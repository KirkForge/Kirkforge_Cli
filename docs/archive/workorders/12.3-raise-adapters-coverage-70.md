## Problem
The `src/adapters` coverage threshold in `.github/workflows/ci.yml:344`
is 61.0%. Current actual coverage (CI run `30275314517`): 63.7%. 2.7%
headroom — tighter than `src/tools` but looser than `src/session`. The
target is 75% (WO 12.8/12.9); this WO is the intermediate step to 70%.

## Root cause
`src/adapters/` (1492 lines) contains the model adapters: Anthropic
(native Messages API), OpenAI-compat, Ollama-NDJSON, Bedrock (SigV4),
Vertex (OAuth2), and the adapter dispatch/mod.rs. The Anthropic
adapter is well-tested (SSE parsing, `cache_control` markers, thinking
blocks, `tool_use` blocks). The Bedrock/Vertex adapters have tests for
the signing paths but the actual HTTP send + response-parse paths are
thinly covered because tests mock the HTTP client. The adapter
dispatch (`mod.rs`) has tests for the routing logic but the
error-recovery + retry paths may be uncovered.
