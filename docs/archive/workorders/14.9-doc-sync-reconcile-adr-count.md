## Root cause
The doc-sync rule (AGENTS.md §9) is enforced by human discipline, not
 by a test. The `adr_xref_drift` test catches ADR-header-vs-index
 drift, but no test catches `TECHNICAL.md` / `state.md` count drift.
 Over 11 series of WOs, each touching docs in its own commit, the
 aggregate counts fell out of sync. This is the classic "stale doc
 in the same session it was written" failure AGENTS.md §9 was written
 to prevent — and it happened anyway because the rule is manual.
