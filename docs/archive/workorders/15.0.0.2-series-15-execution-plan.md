## Execution strategy
- **Wave 1:** 15.1, 15.2, 15.3, 15.4 (Phase 1 — Tier 1, all independent, parallel)
- **Wave 2:** 15.5 (Phase 2 — test split, alone, gates everything after)
- **Wave 3:** 15.6, 15.7, 15.8, 15.9, 15.10, 15.11 (Phase 3 — Tier 2, parallel where non-overlapping)
- **Wave 4:** 15.12, 15.13, 15.14, 15.15 (Phase 4 — god-tier refactors, parallel — different subsystems)
- **Wave 5:** 15.16, 15.17, 15.18, 15.19 (Phase 5 — Tier 3, parallel where non-overlapping)
- **Wave 6:** 15.20, 15.21, 15.22 (Phase 6 — remainder, parallel)
- **Wave 7:** 15.23, 15.24, 15.25 (Phase 7 — Tier 4 polish, parallel)
- **Review subagent:** after each wave, a fresh subagent reviews the merged changes and reports to the orchestrator

## Gate
Each WO has its own gate (listed above). The series gate is:
```
cargo fmt --check && cargo clippy --all-targets -- -D warnings &&
cargo test --locked --workspace --no-fail-fast &&
cargo test -p plugin3-core --test adr_xref_drift
```
