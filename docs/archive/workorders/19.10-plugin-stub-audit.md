# Workorder 19.10 — Plugin Module Stub Audit

## Status: Planned

## Problem

All 5 plugin modules (stratum, kf-budget, kf-draw, kf-video, kf-workflow) plus the
plugin infrastructure (kf-plugin-host, kf-plugin-sdk, plugin_tools) were audited
file-by-file for stubs, TODOs, silent failures, skeleton implementations, and
dead code creeping in. This WO documents the findings.

## Audit scope

Every `.rs` file in every module was read in full. Shell fallback scripts in
`plugins/*/` were also checked. Total: ~90 source files across 7 crates and 5
session integrations.

## Action items

### Fix now (medium severity)

1. **#1**: `StratumConfigValidate::run` should call `load_effective_config()` and report `valid: false` on failure — mirrors what `pre-tool-bash` hook already does at line 484.
2. **#4**: `check_and_slice` at `budget.rs:166` — add `tracing::warn!("budget slicer error, keeping full result: {e}")` before returning `Keep`.
3. **#6**: `cost.rs:112` — add `tracing::warn!("failed to write usage record: {e}")` before the `let _ =`. Requires adding `tracing` dependency to `kf-budget-core` (or keep `eprintln!` consistency and skip).
4. **#23**: `kf-workflow eval_condition` — change `Err(_) => false` to `Err(e) => { tracing::warn!("condition eval failed: {e}"); false }`.
5. **#24**: `kf-workflow handle_batch_error` — replace `.unwrap()` with `.ok_or_else(|| ...)` or match on `None` and return a proper error.

### Accept as-is (low severity, documented or intentional)

- Documented stubs (#9-12): per ADR-0013, intentional placeholders for host-specific payload handling.
- Silent file cleanup (#14-16, #22): temp file removal on cleanup paths — acceptable.
- Dead code (#2, #3, #13, #18, #20, #21): all harmless, some with explanatory comments.
- Silent transcode result (#19): error path handled by `?`, result genuinely unused.
- Template placeholder (#26): user-facing scaffold text, not a code TODO.
- Style mismatch (#5): `kf-budget-core` has no `tracing` dep — consistent within crate.
