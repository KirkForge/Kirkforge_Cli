# Workorder 19.7 — Shared Test Support Module: De-duplicate Helpers

## Status: Planned

## Problem

6 test helper functions are duplicated across 2–3 files:

| Helper | Locations |
|---|---|
| `make_state` | `tui/events.rs`, `tui/widgets/status.rs`, `tui/widgets/chat/mod.rs` |
| `make_ctx` | `tui/keys/mod.rs`, `session/plugin_tools/wrapper.rs`, `session/verifier/bus.rs` |
| `test_state_with_log` | `tui/mod.rs`, `tui/commands/fork.rs`, `tui/commands/save.rs` |
| `make_config` | `session/adapter_swap.rs`, `session/mcp_client/mod.rs` |
| `test_session_start_hook_returns_allow` | `session/stratum.rs`, `session/budget.rs` |
| `test_state` | `tui/commands/mod.rs`, `tui/commands/plugins/mod.rs` |

These aren't just name collisions — they're the same function copy-pasted with minor
variations. `make_state` in three TUI files each constructs an `AppState` with different
defaults. `test_state_with_log` sets up a temp dir + logger in three places.

## Fix

### 1. Create `src/test_support.rs`

A `#[cfg(test)]` module that exports common helpers:

- `pub fn make_state(conn: ConnectionState) -> AppState` — unified from 3 copies
- `pub fn make_ctx() -> TestCtx` — one version, parameterized as needed
- `pub fn test_state_with_log() -> (AppState, TempDir)` — unified from 3 copies
- `pub fn make_config() -> Config` — with sensible defaults
- `pub fn make_adapter() -> MockAdapter` — re-export from `session/executor/tests/common.rs`

### 2. Create `src/tui/test_support.rs`

TUI-specific helpers:

- `pub fn make_tui_state(conn: ConnectionState) -> AppState` — replaces 3 copies
- `pub fn test_tui_state() -> (AppState, TempDir)` — replaces 3 copies
- `pub fn test_tui_state_with_log() -> (AppState, TempDir, Log)` — replaces 3 copies

### 3. Delete the inline copies

After creating the shared modules, delete the inline copies and import from the
shared module. Run `cargo test --workspace` to verify.

## Verification

- `grep -rn 'fn make_state\|fn make_ctx\|fn test_state_with_log\|fn make_config' src/`
  shows only the shared module definitions, no duplicates
- `cargo test --workspace` passes
- `cargo clippy --workspace --all-targets` no new warnings
