## Scope

This WO covers the top 5 (300+ lines). The 200-299 line targets are lower
priority and can be split in a follow-up.

## Approach

For each function:
1. Identify logical sections (by comment blocks or match arms)
2. Extract each section into a named method on the same `impl` block
3. Original function becomes a thin orchestrator calling the methods
4. Run gates after each extraction: `cargo test --locked --workspace`, `cargo clippy --all-targets`

Ponytail: extract methods, don't refactor the control flow. The goal is
readability, not architectural change.
