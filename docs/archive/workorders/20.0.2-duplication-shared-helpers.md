# Workorder 20.0.2 — Duplication Cleanup: Extract Shared Helpers

## Problem

Copy-pasted logic across adapters, daemon modules, and TUI tests. Every copy
is a maintenance land mine — fix one, miss the other two.

## Targets

### H1. `model_info()` — duplicated across 3 Anthropic adapters (HIGH)

`anthropic.rs:54-70`, `anthropic_bedrock.rs:54-66`, `anthropic_vertex.rs:73-84`

Each has ~30 lines of reasoning/images/cache logic that's nearly identical.

**Fix:** Extract `fn anthropic_model_info(model_id, image_prefix) -> ModelInfo`
into `adapters/mod.rs`. Each adapter calls it with its prefix.

### H2. Auth + signal handler duplication (HIGH)

- `read_auth_token()` + `check_auth()` with `subtle::ConstantTimeEq`: 3 copies
  (`daemon/client.rs`, `jobs/daemon.rs`, `daemon/mod.rs`)
- Signal handler setup (SIGINT/SIGHUP/SIGTERM → `Notify`): 2 copies
  (`daemon/server.rs`, `jobs/daemon.rs`)
- Socket guard + PID file + cleanup: 2 copies
  (`daemon/server.rs`, `jobs/daemon.rs`)
- NDJSON `write_response`/`send_response`: 2 copies
  (`daemon/server.rs`, `jobs/daemon.rs`)

**Fix:** Move shared daemon helpers to `daemon/mod.rs` as `pub fn`s. Server and
jobs daemon both call them.

### H3. `reqwest::Client` construction — 5 sites bypass shared helper (MEDIUM)

`tui/connection.rs:30`, `tui/commands/model.rs:93,342`,
`session/mcp_client/http.rs:67-74`, `session/router.rs:193`,
`session/prompt/summarizer.rs:213`

Only `mcp_client/http.rs` sets `tcp_nodelay`. The rest use bare `Client::new()`.

**Fix:** Extend `build_reqwest_client()` (or create one if it doesn't exist) to
accept a timeout override. All 5 sites call it.

### H4. `AppState` inline construction — 17 remaining sites (LOW)

Files still constructing `AppState::new(Arc::new(RwLock::new(Config::default())))`
inline instead of calling `app_state()`:

`tui/keys/mod.rs` (9x), `tui/commands/route.rs` (2x), `tui/commands/jobs.rs`,
`tui/commands/model.rs`, `tui/commands/carryover.rs`,
`tui/commands/sessions.rs` (4x), `tui/commands/undo.rs`,
`tui/commands/workflow.rs`, `tui/approval_keys.rs` (2x local helpers)

**Fix:** Replace all with `use crate::shared::test_util::app_state;` and
delete the local helpers.

### H5. `MAX_SSE_BUFFER_BYTES` — 3 definitions (LOW)

`anthropic.rs:23`, `openai_compat/mod.rs:52`, `anthropic_bedrock.rs:178`

**Fix:** `pub(crate) const MAX_SSE_BUFFER_BYTES` in `adapters/mod.rs`.

### H6. `format_duration` — 2 signatures (LOW)

`tui/rendering/format.rs:10` (f64), `tui/commands/status.rs:84` (u64)

**Fix:** Unify into one function with `Into<f64>` parameter.
