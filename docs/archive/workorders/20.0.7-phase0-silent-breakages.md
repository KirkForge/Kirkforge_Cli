# Workorder 20.0.7 — Phase 0: Fix Silent Breakages (Production Bugs)

## Problem

Multiple bugs that compile green and pass tests but break in production. These
must be fixed before any other work. Sourced from cross-review findings.

## Targets

### P0-1: Plugin env-var mismatch (CRITICAL)

- **Host** sets `KF_CODE_TOOL_ARGS` + `KF_CODE_TOOL_ARGS_JSON`
  (`src/session/plugin_tools/wrapper.rs:196-197`)
- **Every plugin script** reads `KIRKFORGE_TOOL_ARGS_JSON` (33 occurrences)
- **Result:** all shell-out plugins silently receive `{}` as arguments
- **Fix:** Rename in host OR in all plugin scripts. Add integration test that
  calls a plugin tool with non-empty args end-to-end.

### P0-2: Bedrock + Vertex unwirable (CRITICAL)

- `adapter_for_with_provider` hardcodes Bedrock region `"us-east-1"` and Vertex
  `project_id = ""`, `region = "us-central1"`, `service_account = None`
  (`src/adapters/mod.rs:442-457`)
- Config fields `aws_region`, `aws_profile`, `gcp_project_id`, `gcp_region`,
  `gcp_service_account_path` are parsed and tested — **never plumbed through**
- Vertex URL emits `projects//locations/us-central1/...` — malformed
- **Fix:** Plumb config through (add params to factory, update 5 call sites)
  OR remove Bedrock/Vertex from advertised provider set. Add smoke test.

### P0-3: Anthropic cache-breakpoint explosion (CRITICAL)

- `src/adapters/anthropic.rs:201-231` marks **every prefix message except the
  first** with `cache_control`, plus last system block, last tool, tail
- 20-message conversation ≈ 21 breakpoints. **Anthropic hard limit is 4.**
- Short-conversation tests pass (3-4 messages); bug only fires in production
- **Fix:** Count breakpoints, cap at 4, prioritize system+tools+tail.

### P0-4: Stratum offload markers are dead pointers (CRITICAL)

- Budget guard slices tool result → offloads to `InMemoryOffloadStore` → emits
  `[offloaded: <hash>]` (`crates/kf-compress-core/src/pipeline.rs:238`,
  `src/session/stratum.rs:76`)
- Store is **process-local AND constructed fresh per tool call** — never
  persisted, never queryable after the marker is emitted
- Model sees `[offloaded: abc123]` with no way to retrieve content
- `store_get` budget tool exists but uses a **different store**
- **Fix:** Either make offloaded content retrievable via `store_get`, or drop
  offload and use plain truncation. Dead pointers are worse than truncation.

### P0-5: Budget guard ADR drift (MEDIUM)

- ADR-0047:50 states: "The hooks observe and report budget usage but **do not
  yet slice/compact tool results**"
- `HeadTailSlicer` IS wired (`session/budget.rs:211`, `executor/turn.rs:915,976`)
- Either the ADR is stale or the wiring is incomplete
- **Fix:** Reconcile. If slicing works, update ADR-0047. If not, finish wiring.

### P0-6: `max_parallel: 0` deadlocks fan-out (HIGH)

- `crates/kf-workflow/src/lib.rs:654` — `Semaphore::new(max_permits)` where
  `max_permits` can be 0 if `max_parallel: Some(0)` in workflow JSON
- Every spawned task calls `sem.acquire().await.unwrap()` on a semaphore with
  0 permits → permanent hang, no timeout, no error
- Same pattern correctly guarded in `src/jobs/daemon.rs:124` with `.max(1)`
- **Fix:** Add `.max(1)` or validate `max_parallel >= 1` at parse time. Add
  test `fan_out_zero_max_parallel_is_rejected`.

### P1-6: `bash_output` phantom tool description (LOW)

- `src/tools/bash.rs:244,318` tells model to call `bash_output({id})`
- No `bash_output` tool exists (merged into `bash_status`)
- Model calls it → "unknown tool" → wasted round-trip
- **Fix:** Replace `bash_output` with `bash_status` in tool description strings.
