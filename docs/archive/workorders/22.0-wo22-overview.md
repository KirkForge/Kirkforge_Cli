## Ship-blockers (fix BEFORE anything else)

### 22.0-R1 — Fix landlock ABI + tests
- **Reality-check:** `landlock.rs:31-36` struct has extra `rule_type` field, wrong order, not packed (24 bytes vs kernel 12). `landlock_add_rule` args at `:79-85` swapped (pointer where rule_type should be). `ACCESS_FS_READ` includes WRITE_FILE (1<<1). Tests use `tempfile::tempdir()` whose `TempDir` drops before assertion — vacuous.
- **Scope:** `src/session/bash_runner/landlock.rs` (full rewrite), `src/session/bash_runner/mod.rs`, `src/session/bash_jobs.rs`, `src/tools/bash.rs`
- **Success criteria:**
  - `landlock_path_beneath_attr` is `#[repr(C, packed)] struct { allowed_access: u64, parent_fd: i32 }` (12 bytes, matches kernel UAPI)
  - `landlock_add_rule` called as `syscall(ADD_RULE, ruleset_fd, RULE_PATH_BENEATH as i32, &attr as *const _, 0u32)` — arg 2 is the integer rule type, arg 3 is the pointer
  - `ACCESS_FS_READ` / `ACCESS_FS_WRITE` / `ACCESS_FS_ALL` bit assignments match `linux/landlock.h` (WRITE_FILE=1<<1, READ_FILE=1<<2, etc.)
  - `add_path` failure for workspace → fatal (log error + close fd + return, no `restrict_self`)
  - `add_path` failure for system dirs → skip that dir (log warning, continue to next dir)
  - `restrict_self` failure → fatal (log error + abort the bash launch, per WO 21.7-R5 "refuse if unsandboxed" policy)
  - Test: `landlock_blocks_write_outside_workspace` uses a **kept-alive** `TempDir` (not dropped before assertion). Writes to `$outside_dir/file.txt` and asserts `EACCES`/`EPERM` or file-not-created.
  - Test: `landlock_allows_read_everywhere` reads from `/dev/null`, `/etc/hostname`, `/tmp` — asserts success.
  - Test: `landlock_allows_write_in_workspace` writes inside workspace tempdir — asserts success.
  - `/dev` and `/proc` added to `SYSTEM_READ_DIRS` allow-list
  - Home dir: grant `ACCESS_FS_ALL` (not just READ) to support `cargo`/`rustup`/`npm`
  - XDG dirs: grant `ACCESS_FS_ALL` (read+write) for cache/data
  - Pre-exec: no heap allocation (`env::var` → resolve paths in parent, pass owned `PathBuf` into closure)
  - Both foreground (`mod.rs`) and background (`bash_jobs.rs`) paths wired
  - `state.md` updated: 21.7-R1 no longer claims "DONE" until the above pass
- **Failure criteria:** Any landlock test fails. Any write outside workspace succeeds. `apply_landlock` silently no-ops. Pre-exec allocates heap.
- **Estimate:** L
- **Defer note:** none — this is the ship-blocker.

### 22.0-R2 — Fix folded plugins default-OFF
- **Reality-check:** `config/tools.rs:52-57` `default_plugin_sources()` inserts only `kf-plugin`. `default_enabled_plugins()` derives `["kf-plugin"]`. Stratum/budget compiled-in tools gate on `enabled_plugins` membership → never register with default config.
- **Scope:** `src/shared/config/tools.rs`, `src/session/executor/mod.rs`, `src/main/run_session.rs`
- **Success criteria:**
  - With default config (no user config file), `enabled_plugins` includes `["kf-budget", "kf-plugin", "stratum"]` (or equivalent — the 3 folded/default-on plugin names).
  - `cargo test -p kf-code session::plugin_tools::tests::budget_tools_present_in_default_toolset` passes.
  - `cargo test -p kf-code session::plugin_tools::tests::stratum_tools_present_in_default_toolset` passes (or equivalent).
  - Existing user configs with `enabled_plugins` specified continue to work (no regression).
- **Failure criteria:** Any of the above tests fails. User config regression.
- **Estimate:** S
- **Defer note:** none — this is the ship-blocker.
