# Workorder 22.12 — P1-7 ADR Drift

## Status: Planned

## Problem

~25 ADRs contain path literals (`crates/X`, `src/Y`) that reference old
crate names (`kirkforge-*`, `plugin3-core`) or reorganized paths. These
stale paths make ADRs unreliable as documentation — a developer reading an
ADR can't find the referenced code.

## Source

Review Part 8 §8.3 (ADR path-literal drift). WO 22.0 overview §22.12.

## Targets

### 22.12-R1 — Fix all stale ADR path literals + add drift test (HIGH · est M · dep: 22.8)

**Reality check:** ~25 ADRs under `docs/adr/` contained path literals like
`crates/kirkforge-*` or `src/plugin3-core` that no longer exist in the
repository. The `adr_path_literal_drift` test in `kf-budget-core` checks ADR
header/index consistency but does NOT check whether path literals in ADR
prose actually exist in the repo.

**What was done (another subagent):**
- All ~25 ADRs with dead `kirkforge-*`/`plugin3-core` path literals were
  updated. References like `kirkforge-video` → `kf-video` (or current name),
  `plugin3-core` → current crate name.
- ADR prose was updated to match current repository structure.

**Remaining:**
- Extend the `adr_path_literal_drift` test (in
  `crates/kf-budget-core/tests/`) to assert that every `crates/X` path
  literal in ADR prose actually exists as a directory or file in the repo.
- This test should run in CI (the `quality` job) to catch future drift.
- The test should extract path literals matching `crates/[a-zA-Z0-9_-]+`
  from ADR `.md` files and assert each one exists.

**Scope:** `crates/kf-budget-core/tests/adr_path_literal_drift.rs`,
`docs/adr/*.md`.

**Success criteria:**
- All ADR path literals reference real paths in the repo.
- `adr_path_literal_drift` test checks path existence (not just header/index
  consistency).
- `cargo test -p kf-budget-core --test adr_path_literal_drift` green.
- CI `quality` job includes this test.

**Failure criteria:**
- Any ADR contains a `crates/X` reference where `X` doesn't exist.
- `adr_path_literal_drift` test doesn't check path existence.
- Test not in CI.

**Estimate:** M (ADR paths fixed by another subagent; test extension remains)

**Defer note:** none — the ADR paths are already fixed. Only the test
extension remains, which is a safety net, not a ship-blocker. But it should
be done before closing this workorder.

## Verification

- `grep -r 'kirkforge-' docs/adr/` returns no stale path literals.

- CI `quality` job green.
