## Ordering / dependencies

1. **26.1** (P0 crashes + CI) ships first. F0 and F17 block CI; F2/F3 are panics in user-facing paths.
2. **26.2** (P1 correctness) ships next. F5 (race) and F9 (compaction) are correctness risks in production paths. F6/F7 are silent data-corruption risks.
3. **26.3** (P1 infra) ships after 26.2. F11 (unbounded queues) and F8 (serialized jobs) are throughput bottlenecks. F12 (no daemon timeout) is a reliability risk. These interact with 26.2 fixes (e.g., F5 cancel race and F11 backpressure).
4. **26.4** (P1 features) ships after 26.1-26.3 stabilize. D5 (sessions dirty) and D7 (persona adapter) are high-value completions. R-lint is a one-time decision.
5. **26.5** (P2 features) ships after 26.4. Each D-item is independent and can ship individually. D6 (AppState decomposition) is the largest and highest-risk — gate on green CI.
6. **26.6** (P3 polish) ships last. L14 (dead-id gate) is CI enforcement for work already done in 26.1-26.3. D0 (session coverage) depends on 25.4 llvm-cov tooling.

## Success criteria (whole series)

**Bug fixes (26.1-26.3):**
- All F0–F17 bugs either fixed or explicitly re-deferred with disclosure.
- No new `panic!` / `unwrap` on user-controlled input in committed code.
- CI drift test (F0) is green.
- `cargo build --features landlock` compiles (F17).
- Sub-second timeouts work correctly (F6).
- No run-id collisions at second granularity under concurrent runs (F7).
- Child processes are killed on bash cancel (F5).
- All channels have bounded capacity or documented ceiling (F11).

**Features (26.4-26.5):**
- Daemon clients see fresh session state after mutations (D5).
- Persona adapter routes through user's configured provider for Bedrock/Vertex (D7).
- Non-Rust linting either wired or documented with honest ceiling (R-lint).
- Bash streaming, MCP sampling, memory widget, computer_use, AppState decomposition each shipped or re-deferred with disclosure.

**Polish (26.6):**
- Top-10 slowest tests each under 100ms or explicitly justified.
- Integration tests behind feature gate or separate directory.
- Coverage regression gate active in CI.
- No references to dead crate/binary IDs in active source.

## Failure criteria (whole series)

- Any F0–F3 panic reachable from user input after 26.1 lands.
- F5 (cancel race) "fixed" by swallowing the error instead of killing the child.
- F9 (compaction inversion) "fixed" by raising minimum budget instead of fixing the arithmetic.
- F11 (unbounded queues) "fixed" by adding `try_send` without backpressure handling — silent message drop is a data-loss bug, not a fix.
- D6 (AppState decomposition) ships with a 68-field struct still intact, or with public fields broken without accessors.
- Any item silently stubbed or feature-gated off without explicit defer-disclosure in the sub-WO and `state.md`.
- Session coverage regresses below current baseline.
