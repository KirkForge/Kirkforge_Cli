# WO 33.15 — Reduce #[serial] usage via dependency injection

## Status: Done (no-op: zero #[serial] in repo)

## Problem (as specified)

Reduce `#[serial]` usage in test code: for each `#[serial]`, check whether
the underlying reason (env mutation / shared global state / filesystem/cwd)
is already fixed by WO 33.13 (EnvGuard), and remove `#[serial]` where it
is; keep it with a `// #[serial]: needed because <reason>` comment where
genuinely needed.

## Finding (the actual state of the repo)

- `grep -rn '#\[serial\]' src/ crates/ --include='*.rs'` → **ZERO hits.**
- No `serial_test` dependency in any `Cargo.toml` (root or `crates/*/`).
- `grep -rn 'serial' tests/ benches/ src/ crates/ --include='*.rs'` filtered
  for `#[serial]` / `#[serial_test]` → **ZERO hits.**
- The `serial` substring in `src/shared/event_bus.rs` is unrelated
  (documentation prose about serial-await semantics of the event bus, not
  the test attribute).

**Root cause**: this codebase never adopted `#[serial]`. WO 33.13
(`docs/workorders/33.13-kill-env-mutation.md`) introduced the `EnvGuard`
RAII helper (`src/shared/test_util.rs`) as the parallelism-safety
mechanism *instead of* `#[serial]`. The workorder table in
`33.0-wo33-overview.md` lines 19/68 framed 33.15 as "`#[serial]` used to
compensate for shared global state" + "reduce #[serial] usage via
dependency injection" — but the codebase went straight to EnvGuard and
skipped the `#[serial]` phase entirely. There is no `#[serial]` to reduce.

WITHOUT `EnvGuard` (e.g. `src/adapters/auth.rs` has ~14 raw
set_var/remove_var; `src/session/plugin_tools/tests.rs:201`;
`src/shared/metrics.rs:824`). These are the real parallelism hazards.

- **DEFERRED**: migrating the remaining raw `set_var`/`remove_var` test
  call-sites to `EnvGuard`.
- **Why**: that is WO 33.13's explicit scope ("Kill Global Env Mutation in
  Tests (Phase 2)"), which is still **Status: Pending** in
  `docs/workorders/33.13-kill-env-mutation.md`. WO 33.15 was scoped to the
  `#[serial]` axis only; doing 33.13's work here would be scope creep and
  would duplicate the tracked Pending workorder.
- **Remaining work**: the file list in 33.13
  (`src/session/session_index.rs`, `src/session/verifier/security.rs`,
  `src/adapters/anthropic/mod.rs`, `src/adapters/bedrock/mod.rs`,
  `src/session/config/mod.rs`) plus the additional call-sites noted above.
- **Tracked in**: `docs/workorders/33.13-kill-env-mutation.md` (Pending).
