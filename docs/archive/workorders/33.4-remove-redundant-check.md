# WO 33.4 — Remove Redundant cargo check

## Status: Done (CI runs `cargo clippy` only; no separate `cargo check`)

## Problem
`ci-merge.yml` runs `cargo clippy --all-targets` then `cargo check --workspace --all-targets`. Clippy is a superset of check — it compiles everything check does plus lint warnings. The check step is pure duplication.

## Approach
Remove the `cargo check` step from `ci-merge.yml` and `ci-pr.yml` if present. Clippy is the compile gate.

## Files
- `.github/workflows/ci-merge.yml`
- `.github/workflows/ci-pr.yml`

## Gate
- YAML valid
- Clippy still runs

## Done
No redundant cargo check in CI. Clippy is the sole compile gate.
