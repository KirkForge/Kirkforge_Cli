# WO 33.9 — Windows: Split Tests from Release Build

## Status: Done (Windows tests in `ci-merge.yml:188-192`; release in `ci-nightly.yml`)

## Problem
The Windows CI job runs tests AND a release build. Release compilation is not a test — it's artifact validation. Coupling them means every test run pays for a release build.

## Approach
1. Keep the Windows test job in `ci-merge.yml` (tests only, no release build).
2. Move the release build to `ci-nightly.yml` (already has `release-build` matrix job — verify it covers Windows).
