# WO 34.9 — Slash command taxonomy: everyday/advanced/developer

## Status: Done

## Problem

`src/tui/keys/slash_commands.rs:44-240` lists 30 commands across 6
groups (Session, Model, Safety, Workflow, Plugins, Diagnostics). The
completion popup (`slash_menu.rs`) shows them alphabetically by trigger,
not by frequency or importance. `/help` dumps all 30 equally weighted.

## Approach

1. Reorganize the `GROUPS` const into 3 tiers:
   - **Everyday**: /clear, /help, /model, /compact, /sessions, /commit,
     /undo, /status
   - **Advanced**: /plugins, /workflow, /mcp, /metrics, /verify, /memory,
     /permissions, /route, /save, /fork, /resume, /thinking, /theme,
     /carryover, /reload
   - **Developer**: /test, /gh, /init, /explore, /plan, /coder,
     /implement
2. The completion popup ranks Everyday commands first, then Advanced,
   then Developer — within each tier, alphabetical.
3. `/help` (when converted to an overlay in WO 34.2) shows the 3 tiers
   with Everyday expanded and Advanced/Developer collapsed.
4. Update the `GROUPS` const and the `help_text()` function.
5. Update tests (`slash_command_table_covers_all_triggers`,
   `help_text_groups_cover_all_commands`) for the new group names.

## Files to touch

- `src/tui/keys/slash_commands.rs` — reorganize GROUPS + COMMANDS
- `src/tui/widgets/slash_menu.rs` — ranking by tier
- Tests in `slash_commands.rs`
