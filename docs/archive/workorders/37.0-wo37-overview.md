## Items

1. **BashJobRegistry hardening (WO 37.1).** Three real defects in
   just-shipped code: (a) per-manager owner ids — `format!("task-{}",
   self.next_id)` (`src/tools/task.rs:281`) — collide across managers,
   so one manager's cancel can reach another manager's same-tagged
   jobs (the disclosed ceiling); (b) `remove()` on a running job still
   parks on the watcher-held child mutex (same flaw 36.2 fixed in
   `cancel()`); (c) phantom job: registry insert at
   `bash_jobs.rs:195` happens before `proc.spawn()?` at :240 — spawn
   failure leaves a Running job with no child (the :273 comment knows).
2. **The reducer (WO 37.2).** Last "NOT ported" piece of
   kf-orchestrator. NO TS source exists in this repo (verified) — this
   is a design-from-contract task, not a port: fold
   `kf_routing::correction` state types (`Changes`, `GraphState`,
   `LintState`, `TypesState`, `SecurityState`, `Verification`,
   `OverallVerdict`) into `ReducedStatePacket` so
   `DelegationResult.packet` stops being always `None` (delegate.rs:269),
   and wire it into the correction loop's decide step.
