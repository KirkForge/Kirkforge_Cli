# WO 38.12 — Test hygiene completion

## Status: Done

## Problem (flake audit — 3 flake classes remain + stale ignore)

Anti-flake standard (established 35.x/36.x): event-driven, structural
assertions, hermetic, no sleep-races, no wall-clock margins.

1. **Wall-clock margins**: `test_mid_batch_checkpoint_persists_
   partial_results` (50ms margin — the GatedSleepTool already has a
   gate channel: fire after first tool completes); `shutdown_notify_
   wakes_select` (drop redundant 500ms bound); subagent-lifecycle
   `elapsed < 5s` redundant with its own timeout wrapper; dispatch
   `attached_cancel_token...` 10s bound (low risk, convert anyway).
2. **Sleep-sync**: 400ms "bash is now mid-sleep" (subagent test) →
   poll registry Running status; 300ms cancel timers → gated-start
   signals (3 sites); `recent_list_is_capped` 10ms mtime staggering →
   set mtimes explicitly.
3. **Order dependence in the single lib test binary** (nextest-immune,
   but the repo's own test-fast gates are threaded): unguarded
   `set_current_dir` in glob.rs + tui/commands/workflow.rs (2 tests)
   — hoist one RAII CwdGuard + lock into shared test_util;
   `session_mode_round_trip` mutates global SESSION_MODE unlocked.
4. **Stale `#[ignore]`**: `handle_jobs_command_cancel_running_job_
   succeeds` — root cause fixed in 36.2; un-ignore with a
   poll-until-Running replacing the 100ms sleep.
5. **Machine-state**: process_group tests spawn unix `true`/`sleep`
   ungated (works on GH runners via git-coreutils PATH — fragile);
   gate `#[cfg(unix)]`; glob fixed-temp-path → tempfile.

## Approach

One commit per class; the shared CwdGuard lands first (new test_util
helper), then the conversions. No behavior changes to production code
except none — tests only.

## Gate

5× repeated runs of every touched test; full lib suite threaded
(`scripts/test-fast.sh`) AND nextest both green; `git grep '#\[ignore'
src/` reviewed with only honest reasons remaining.

## Done condition

Zero remaining wall-clock-margin or sleep-sync assertions outside
sanctioned bounded-poll helpers; every global-state mutation guarded;
the stale ignore resurrected.
