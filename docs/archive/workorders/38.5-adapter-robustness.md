# WO 38.5 — Adapter robustness

## Status: Done

## Problem (adapter audit — provider neutrality is the moat; the moat has cracks)

1. **P0 — one turn-fatal error ends the session** (loop_.rs:538-547):
   429/5xx surviving 3 retries, any 401/403/404, missing key →
   executor exits; input silently discarded afterwards (matches TUI
   audit P1-1's zombie-session finding).
2. **P1 — Anthropic-family usage never captured** (sse.rs:121-171):
   parser reads usage from `message_stop` (which the real API never
   carries) and ignores `message_delta`/`message_start` usage →
   CostStats never fires on Anthropic/Bedrock/Vertex → $0 forever.
   Tests encode the mock's wrong shape (mod.rs:1614-1633).
3. **P1 — pricing table matches none of our model names**
   (shared/mod.rs:765-808): prefixes `opus-4`/`sonnet-4`... vs real
   ids `claude-sonnet-4-…`, `anthropic.claude-3-5-…`, `big-pickle`,
   `glm-5.1:cloud` → everything falls to the $0 sentinel.
4. **P1 — truncation semantics divergent + lossy**: OpenAI-compat/
   Ollama channel-close discards the partial assistant message
   entirely (turn.rs:1110→1247 — unlike the cancel path which
   flushes); Anthropic launders truncation into a SUCCESSFUL turn
   (synthesized Done(Stop) at sse.rs:207-220) → half-reply persisted
   as complete.
5. **P1 — cache poisoning** (caching.rs:104-110, 302-307): streams
   containing Error events get cached (because Anthropic always ends
   with a synthesized Done) and replayed forever; cache hits re-bill
   the old usage in CostStats.
6. **P1 — zero-arg tool calls dropped** on Anthropic family
   (content_block_stop gate) and error-loop on OpenAI-compat
   (`arguments:""` → parse-error retries → turn dies).
7. **P1 — `openai_api_key` is dead config** (mod.rs:514-518 vs
   openai_compat/mod.rs:354-368): never threaded; hosted OpenAI-compat
   endpoints 401 → session death via #1.
8. **P1 — Bedrock envelope offsets on lossy string**
   (anthropic_bedrock.rs:213-229): byte offsets computed on
   from_utf8_lossy output but drained from raw buffer → frame
   corruption on non-UTF8 preludes.
9. **P1 — OpenAI-compat never sends `stream_options: {include_usage}`**
   and drops the post-finish usage frame.

## Approach (in fix order)

1. Executor survives turn errors: emit Error event, keep the loop
   alive (user retries); reserve exit for channel closure. This is
   also TUI P1-1's fix.
2. Anthropic usage: parse `message_delta` + `message_start` usage,
   prefer in send_done; fix the mock tests to wire shapes.
3. Pricing: add `claude-*`/`anthropic.claude-*` rows + config-driven
   price overrides; WARN on unmapped models instead of silent $0.
4. Truncation: one semantic — channel-close-without-Done mirrors the
   cancel path (persist partial marked truncated, Done{Error}); stop
   synthesizing Done(Stop) after a transport error.
5. Cache: never cache streams containing Error; zero the usage on
   replay + cache-hit flag.
6. Zero-arg: flush pending_tool unconditionally at content_block_stop;
   empty-args-with-name → single invocation `json!({})`.
7. Thread `openai_api_key` through the constructor (per-request
   resolution like Anthropic).
8. Bedrock: raw-byte scan for `{` + from_slice parsing, offsets in
   byte space.
9. Send `stream_options`; hold Done until usage frame or [DONE].

## Gate

clippy/fmt/nextest; per-fix regression tests (wire-shape fixtures for
2, 4, 8 — real-format frames, not mock-shaped); existing adapter
suites green.

## Done condition

A provider blip costs one turn, not the session; cost is real on all
six adapter kinds; truncation and zero-arg semantics match across
adapters; the cache can't poison.
