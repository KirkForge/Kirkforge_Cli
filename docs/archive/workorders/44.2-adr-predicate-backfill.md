# WO 44.2 — Finish the ADR predicate-block backfill (43.15 step 4)

## Status: Done

## Problem

WO 43.15 (Done) approach item 4: "Backfill remaining ADRs mechanically
(block derives from existing header + index row) as a follow-up commit;
flip the test to require a block on every ADR only after backfill." The
pilot landed (predicate blocks + `parse_predicate_block` cross-checks in
`crates/kf-budget-core/tests/adr_xref_drift.rs:297`), but the backfill and
the require-all flip never happened, and no deferral discloses that:

- Only 8 ADR files carry a block (004, 025, 029, 044, 048, 049, 054, 073)
  out of 94 ADRs in `docs/adr/`.
- The drift test skips files without a block —
  `crates/kf-budget-core/tests/adr_xref_drift.rs:433-435`
  (`let Some(block) = parse_predicate_block(&body) else { continue; }`) —
  so for the other 86 ADRs the predicate layer enforces nothing and a
  header/index/predicate mismatch there is invisible.
- The 43.15 Done claim ("grep-able answers to 'which accepted ADRs are
  unimplemented', 'what does ADR-048 supersede', 'which ADRs affect
  kf-routing'") holds only for the pilot set; repo-wide it is false, and
  `state.md` pending has no entry for the remaining backfill.

## Root cause

The follow-up commit the approach explicitly sequenced was never made and
never disclosed — a silent partial landing of a "Done" workorder.

## Approach

1. Mechanically add the HTML-comment predicate block to every ADR lacking
   one, deriving `status`/`implemented` from the existing header (the
   compound-status reduction already exists in the test:
   `implemented_from_header`) and `supersedes`/`affects-crates` from the
   prose/index (empty lists allowed).
2. Flip the drift test: replace the `else { continue; }` skip with a
   failure for any ADR file without a block (keep the README-index rows
   exempt if any deliberately stay blockless — name them in the test).
3. Gate output pasted with the count of ADRs now enforced (should be 94).

## Files

- docs/adr/*.md (86 files, comment-block only)
- crates/kf-budget-core/tests/adr_xref_drift.rs

## Gate

`cargo test -p kf-budget-core --test adr_xref_drift` — all predicate
checks green over the full ADR set; a deliberately flipped `implemented`
value in one backfilled ADR fails the test. `scripts/ci-local.sh quick`.

## Done

Backfilled the `<!-- adr-predicates … -->` HTML-comment block into all
86 ADR files that lacked one (8 pilot ADRs already carried one). Every
ADR in `docs/adr/` (94 total) now carries a block, and the drift test
requires one on every ADR file.

- `status` / `implemented` derived from each ADR's existing Status
  header, matching the test's `implemented_from_header` reduction
  (superseded → false, partially implemented → partial, fully
  implemented → true, plain Accepted → true, rejected → false).
- `affects-crates` derived conservatively from `crates/X` path
  literals in prose that resolve to existing crate dirs (empty lists
  allowed and common — many ADRs describe decisions with no
  satellite-crate surface).
- `supersedes` derived from explicit "supersedes/replaces ADR-NNNN"
  patterns in prose (empty for all backfilled ADRs; the only
  superseded ADRs — 048, 049 — were pilots and already carried `[]`).
- Block format matches the 8 pilot ADRs exactly: H1, blank, block,
  blank, rest.

Flipped the drift test (`crates/kf-budget-core/tests/adr_xref_drift.rs`
`adr_predicate_blocks_cross_check_header_crates_and_supersedes`):
replaced the `else { continue; }` skip at line 433 with a failure for
any ADR file without a block. README.md (the index) remains the only
deliberately blockless file and is still skipped by the existing
`if file == "README.md" { continue; }` guard above the new check, so
it is named in the test comment as the exempt file.

Gate verified:
- `cargo test -p kf-budget-core --test adr_xref_drift` — 6/6 green
  over the full 94-ADR set.
- Flipped a backfilled ADR's block off → test fails with
  "no `<!-- adr-predicates … -->` block — WO 44.2 requires one on
  every ADR" (gate is real, not vacuously green).
- Flipped a backfilled ADR's `implemented` value → test fails with
  "predicate implemented [partial] != header [Accepted] (expected
  true)" (cross-check is real).

94 ADRs now enforced.
