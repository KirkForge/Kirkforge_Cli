# WO 44.52 — PR CI silently skips all Rust checks when package classification fails

## Status: Done

## Problem

`scripts/changed-packages.sh` collapses "classification failed" into the same
output as "no packages affected":

- `scripts/changed-packages.sh:60-65` — if `git diff` fails (base ref not
  resolvable), the script prints an **empty list** to stdout and exits 0. The
  comment states this is deliberate: "fall back to an empty change set (caller
  skips tests) rather than crashing the CI step".
- `.github/workflows/ci-pr.yml:116` — the caller adds a second layer of
  swallowing: `pkgs="$(bash scripts/changed-packages.sh "$base" 2>/dev/null || true)"`.
  A crashed classifier and a clean docs-only run are indistinguishable.
- `.github/workflows/ci-pr.yml:118` treats empty output as "no Rust changes";
  `:133` and `:157` then SKIP both the `clippy` and `fast-tests` jobs.

Concrete bite: fork PRs. On a fork, `origin` points at the fork repo and
`origin/${{ github.base_ref }}` (ci-pr.yml:115) does not exist, so
`git diff origin/dev...HEAD` fails → empty output → `clippy` + `fast-tests`
skip → the PR check suite is green with **zero Rust checks run**. The same
happens for any history gap where the base ref can't resolve. Skipped required
checks report as success, so branch protection does not save it.

The `__NO_RUST_CHANGES__` sentinel (changed-packages.sh:111,118) exists
precisely so callers can distinguish "docs-only" from other states — but the
error path reuses empty-string, which the caller also maps to skip.

## Root cause

A three-state result (rust-changes / docs-only / classification-error) is
encoded in two signals (package list / empty string), and the caller wraps the
script in `|| true` on top. Crash-aversion in the script plus error-swallowing
in the workflow turns every classifier failure into a silently untested PR.

## Approach

1. `scripts/changed-packages.sh`: on `git diff` failure, print the diagnostic
   to stderr and **exit non-zero** (drop the fall-back-to-empty at :60-65).
   Empty stdout remains valid only for the genuine no-mapping case (:164-168).
2. `.github/workflows/ci-pr.yml:116`: drop `2>/dev/null || true` so a
   non-zero classifier exit fails the `changes` job (and therefore the check
   suite) instead of skipping downstream jobs.
3. Keep the `__NO_RUST_CHANGES__` docs-only path exactly as is.

  non-zero on git/usage failure — caller must propagate"). The genuine
