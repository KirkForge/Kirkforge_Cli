# WO 44.56 — impact-fallback.sh runs uncapped workspace tests; documented OOM hazard

## Status: Done

## Problem

`scripts/impact-fallback.sh:61` runs `cargo test --locked --workspace` with no
test-thread cap and no nextest. Two other scripts document, as a hard
invariant with an incident behind it, that this exact invocation kills the
host:

- `scripts/test-full.sh:10-15` — "the workspace fans out ~38 integration test
  binaries and each spawns a tokio runtime; uncapped `cargo test --workspace`
  OOMs the host (this killed a prior session — see lessons.md)" → caps at
  `min(nproc, 8)`, honoring `KF_TEST_THREADS`.
- `scripts/ci-local.sh:38-43` — same cap, same rationale, for the cargo-test
  fallback path.

`impact-fallback.sh` (whose whole purpose is a heavyweight check/test/clippy
matrix, `:60-62`) predates the mitigation and was never updated. Anyone
reaching for it on this host reproduces the OOM that motivated the cap
everywhere else.

## Root cause

The thread-cap mitigation was applied to the named gates (ci-local,
test-fast, test-full) but not to the fallback script that runs the same
command; no shared helper enforces it, so it drifts.

## Approach

1. In `scripts/impact-fallback.sh`, mirror the test-full.sh fallback exactly:
   `THREADS="${KF_TEST_THREADS:-$(nproc)}"; cap at 8; cargo test --locked
   --workspace --no-fail-fast -- --test-threads="$THREADS"`.
2. Optional, one line while there: use nextest when available (same
   `command -v cargo-nextest` pattern as the other scripts). Skip if it adds
   more than a few lines — the cap is the load-bearing fix.

## Files

- `scripts/impact-fallback.sh`

## Gate

- `bash -n scripts/impact-fallback.sh`.
- `grep -n 'test-threads' scripts/impact-fallback.sh` → present and capped at 8.

## Done

`scripts/impact-fallback.sh:60-77` — replaced the uncapped
`cargo test --locked --workspace` with the test-full.sh pattern:
- `cargo nextest run --profile ci-full --workspace --no-fail-fast --locked`
  when `cargo-nextest` is on PATH (nextest manages its own thread pool);
- else `cargo test --locked --workspace --no-fail-fast -- --test-threads="$THREADS"`
  with `THREADS="${KF_TEST_THREADS:-$(nproc)}"` capped at 8.

Gate: `bash -n scripts/impact-fallback.sh` clean; `scripts/test-fast.sh` green;
`cargo fmt --check` clean. No deferrals.
