# Workorder 8.4 — Embedding Quality: Evaluate and Tune TF-IDF Retrieval

## Status: Done

## Problem
WO 7.9 added TF-IDF embeddings and graph-walk retrieval, but the embedding quality has never been evaluated. The TF-IDF tokenizer splits on snake_case and whitespace, but code has specific patterns (lifetimes, generics, doc comments, macro invocations) that may not tokenize well. The retrieval quality (does the agent get the right context?) is unmeasured.

## Root cause
Phase 7 was implemented as a functional MVP — it works, but its quality is untested. No evaluation harness exists for context retrieval.

## Files to touch
- `crates/kirkforge-context-index/src/embeddings.rs` — improve tokenizer:
  - Handle `<'a>` lifetime syntax (split lifetime from type name)
  - Handle `Vec<T>` generics (extract `Vec` and `T` as separate tokens)
  - Handle doc comments (weight `///` comments higher than code)
  - Handle macro invocations (`println!` → `println`, `vec!` → `vec`)
- `crates/kirkforge-context-index/src/graph_walk.rs` — add edge weighting:
  - Call-graph edges weighted higher than import edges (calling is a stronger relationship than importing)
  - Same-file symbols weighted higher than cross-file
- `crates/kirkforge-context-index/tests/` — add retrieval quality tests:
  - `test_retrieve_finds_function_by_name` — exact name match → graph walk finds callers
  - `test_retrieve_finds_struct_by_doc_comment` — free-text query matching doc comment → embedding similarity finds the struct
  - `test_retrieve_ranks_closer_symbols_higher` — a symbol 1 hop away ranks higher than 2 hops
  - `test_embedding_similarity_identical_symbols` — same symbol name + kind → high similarity
  - `test_embedding_similarity_unrelated_symbols` — unrelated → low similarity

## Approach
1. Improve the tokenizer with code-specific patterns
2. Add edge weighting to graph-walk (call > import, same-file > cross-file)
3. Write retrieval quality tests that assert the right symbols are found for specific queries
4. Optionally: run the bench harness with the improved retrieval and measure if pass rate improves
