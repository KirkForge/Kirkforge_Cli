ADR-count rows were not touched. This is a recurrence of the doc-sync
regression the review series has flagged since the third pass
(AGENTS.md §9: "Leaving docs stale after a code change is a regression").

## Root cause
The 9-series was delegated to subagents (per the commit messages:
"Wave 1 of the 9-series (4 workorders, delegated to subagents)"). The
subagents updated the rows they touched (bench task count, 9.x status
summary) but missed the main-SHA row (which they didn't change) and the
ADR-count row (which they should have bumped for each new ADR). The
orchestrator (parent session) did not run the full doc-sync checklist
before handing back.
