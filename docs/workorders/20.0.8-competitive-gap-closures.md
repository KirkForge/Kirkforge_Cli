# Workorder 20.0.8 — Competitive Gap Closures (Phase 2)

## Problem

The cross-review identified capability gaps vs Claude Code, Codex CLI, and
opencode that directly affect daily usability. These are not nice-to-haves —
they're the features users hit in the first hour.

## Targets

### G1: Add regex support to `grep` tool (HIGH)

- `grep.rs:186` uses `line.contains(pattern)` — literal substring only
- Cannot do `fn\s+\w+`, case-insensitive, or scoped search
- Daily friction for a coding agent
- **Fix:** Swap to `regex` crate (already a transitive dep) or shell to `rg`.
  Add `--regex` flag to tool definition. Preserve literal mode as default.

### G2: Add PTY + streaming output to `bash` (HIGH)

- `bash_runner/mod.rs:397-479` — no PTY, no stdin, no streaming
- `npm login`, `gh auth login`, `python -i`, password prompts → all hang
  until timeout
- Claude Code's bash streams and supports interactive commands
- **Fix:** Add `portable-pty` or equivalent. Gate behind `--interactive` flag.
  Preserve current non-interactive mode as default.

### G3: Add `replace_all` / multi-edit to `edit_file` (MEDIUM)

- Refactors that touch N identical call sites require N tool calls
- Claude Code supports `replace_all` in its edit tool
- **Fix:** Add `replace_all: bool` to `edit_file` args. When true, replace
  all occurrences in the file instead of unique-match.

### G4: Add `tool_choice` forcing + JSON-schema output (MEDIUM)

- Only `"auto"` is ever set for `tool_choice`
- No JSON-schema structured outputs — only `{type:"json_object"}`
- Both are one-trait-change away from the adapter side
- **Fix:** Add `tool_choice: Option<ToolChoice>` to adapter trait. Add
  `response_format: Option<ResponseFormat::JsonSchema>` to the request builder.
  Wire through Anthropic + OpenAI adapters.

### G5: Emit `thinking:{...}` request when `supports_thinking` (MEDIUM)

- `supports_thinking` flag exists but `build_anthropic_body` never emits the
  `thinking` parameter
- Current code parses thinking blocks from responses but never requests them
- **Fix:** When `supports_thinking && config.extended_thinking`, emit
  `thinking: {type: "enabled", budget_tokens: N}` in the Anthropic request.

### G6: Decompose `AppState` from 68 fields (MEDIUM)

- `AppState` has 68 fields, not 44+ as docs claim
- Borrow-checker workarounds already in render path (`mem::take` dance)
- Comments already group fields into logical sub-structs
- **Fix:** Split into `ApprovalState`, `SearchState`, `DaemonState`,
  `RenderCache`, `GenerationState`. Keep `AppState` as the top-level struct
  holding sub-structs.

### G7: Fix `lessons.md:21` — F1–F6 tabs are shipped, not missing (LOW)

- `lessons.md:21` claims F1–F6 tabs are MISSING; they're fully implemented
- Will cause a worker to re-implement shipped features
- **Fix:** Update `lessons.md` to reflect reality.

### G8: Add `replace_all` / multi-edit to `edit_file` (MEDIUM)

(Duplicate of G3 — removing from tracking)

### G9: Doom-loop remediation, not just detection (MEDIUM)

- `loop_.rs:99-111` detects doom loops (banner + metric) but doesn't act
- No auto-remediation: no forced plan-mode, no hint injection, no loop break
- Burns tokens indefinitely in unattended runs
- **Fix:** Add configurable auto-remediation: after N consecutive tool-call-only
  turns, inject a system hint suggesting plan mode or force `/compact`.

### G10: `FinishReason::Length` silently swallowed (MEDIUM)

- `turn.rs:308-317` — max-tokens ends the turn with zero feedback to model or
  user
- No continuation prompt, no warning
- **Fix:** When `FinishReason::Length`, inject a continuation message and
  re-prompt, or at minimum display a warning to the user.

### G11: Non-file tool durations always 0 (LOW)

- `turn.rs:991` — tool duration metrics are recorded but non-file tool
  durations are always 0
- Can't profile slow tools
- **Fix:** Record actual wall-clock duration for all tool calls, not just
  file tools.

## Verification

- `grep --regex` tool call returns regex-matched results
- `bash --interactive` supports PTY commands
- `edit_file --replace_all` replaces all occurrences
- `tool_choice: {type: "tool", name: "X"}` forces tool use in Anthropic
- Extended thinking requested when config enables it
- Doom loop auto-remediation triggers after N consecutive tool-only turns
- `FinishReason::Length` produces user-visible warning
