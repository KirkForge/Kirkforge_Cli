# Workorder 20.0.9 — Scope, Focus & Trust Hardening (Phase 1 + 4)

## Problem

The cross-review identified scope creep (34K LOC in draw+video with zero users),
trust gaps (advisory-only audit, best-effort signing, rlimits-only sandbox), and
overclaims in documentation. These dilute the core and undermine trust.

## Targets

### S1: Make `kf-video` a non-default feature, then spin off (HIGH)

- 11,213 LOC, zero users, broken default path (shell fallback broken by P0-1)
- Shell fallback receives `{}` args (see WO 20.0.7 P0-1)
- No `brand.json` anywhere in the repo — even the author never used it
- Already feature-gated (`video` feature, off by default)
- **Fix:** Keep feature-gated off. Remove from default workspace members.
  Document that `kf-video` is incubating and may be spun off. Fix P0-1 first
  so the shell fallback works if feature is enabled.

### S2: Make `kf-draw` default-OFF, evaluate for spin-off (MEDIUM)

- 22,939 LOC (`kf-draw` + `kf-draw-core`), zero external users
- `.td.json` format has no external consumers
- Currently default-ON, pulling `unicode-segmentation` + `unicode-width`
- **Fix:** Make `draw` a non-default feature (currently default). Document
  in TECHNICAL.md that it's incubating. If no users after 2 months, spin off.

### S3: Collapse `kf-compress-hosts` into `kf-compress-core` (MEDIUM)

- 151 LOC total — one function in a separate crate with its own build.rs,
  Cargo.toml, docs/, tests/
- **Fix:** Inline the `filter_by_mode` function into `kf-compress-core`.
  Delete the crate. Update workspace Cargo.toml.

### S4: Collapse `kf-budget-hosts` stubs (MEDIUM)

- 843 LOC, but Cursor/Aider/KfCode modules are "stub modules that document the
  intended shape when a future contributor adds a second host"
- Only Claude Code host is wired
- **Fix:** Remove the stub modules. Keep only the wired host. Document the
  multi-host intent in ADR if not already there.

### S5: Fix 5 rigged bench tasks (MEDIUM)

- `use_draw_render`, `use_workflow_run`, `use_budget_check`,
  `use_stratum_compress`, `use_lsp_query` — all verify against setup files,
  not agent output
- An agent doing literally nothing scores 100%
- **Fix:** Add `requires_model = true` and verify real agent output. This
  test would have caught P0-1.

### S6: Reconcile Stratum/TECHNICAL.md overclaims (MEDIUM)

- `TECHNICAL.md:383-389` claims "content-type-specific transforms with offload
  storage and query-based relevance filtering"
- Reality: `CompressionPipeline::new()` is empty in production (see WO 20.0.7
  P0-4)
- `compaction_use_llm` is a misnomer — it's heuristic keyword extraction, not
  LLM (see `microcompaction.rs:228`)
- **Fix:** Downgrade TECHNICAL.md claims to match reality. Rename
  `compaction_use_llm` to `compaction_use_heuristic` or add a doc comment.

### S7: Make `cargo audit` blocking on critical/RCE (HIGH)

- `.github/workflows/ci.yml:398` — `continue-on-error: true`
- A real RCE advisory would not fail CI
- **Fix:** Remove `continue-on-error`. Add `--deny warnings` or at minimum
  `--deny unmaintained` for critical severity.

### S8: Make cosign signing blocking on release (MEDIUM)

- `.github/workflows/release.yml:223` — `continue-on-error`
- Releases can ship unsigned
- **Fix:** Remove `continue-on-error`. If cosign fails, the release fails.

### S9: `SandboxEnforcer` naming overclaim (LOW)

- `src/session/executor/sandbox.rs:7` — name implies enforcement but it's
  `PathGuard` + `DenyList` + `ReadGate` (rlimits, no OS isolation)
- **Fix:** Rename to `PathGuardEnforcer` or add a `// ponytail: not a sandbox,
  upgrade path: seccomp/landlock` comment. Already noted in PONYTAIL-DEBT.

### S10: HTML→"markdown" is regex tag-stripping (LOW)

- `web_fetch.rs:370-395` — loses headings, lists, tables, code fences
- Returns plain text, not markdown
- **Fix:** Use `html2text` crate (already a dep?) or `pulldown-cmark` HTML
  passthrough. At minimum, document the limitation in the tool description.

### S11: TF-IDF `doc` field is dead code (MEDIUM)

- `embeddings.rs:82-100` — `DocLookup` slot + doc-tokenization plumbing exists
  but `Symbol` has no `doc` field; every caller passes `None`
- Cannot find `UserAccount` from query "customer profile" unless names overlap
- **Fix:** Either extract doc comments into `Symbol.doc` (the plumbing exists)
  or remove the dead `DocLookup` code.

### S12: Memory never auto-populates (LOW)

- No tool/hook writes facts to persistent memory
- The entire subsystem can silently no-op
- **Fix:** Add a `remember` tool + system-prompt instruction that writes facts
  to the memory store after significant turns.

### S13: `RetryTracker` dead code (LOW)

- `error_recovery.rs:380-417` — instantiated at `turn.rs:277` but `can_retry()`
  never called
- **Fix:** Remove or wire up. Covered in WO 20.0.6.

### S14: 47 `tracing::debug!` calls exceed AGENTS.md §5 (LOW)

- AGENTS.md §5 says "no debug spam in committed code"
- 47 is a lot of debug spam
- **Fix:** Audit and remove debug-level tracing in hot paths. Convert to
  `tracing::trace!` or remove entirely.

## Verification

- `kf-video` feature-gated off, not in default workspace members
- `kf-draw` feature-gated off
- `kf-compress-hosts` crate removed
- Bench tasks with `requires_model = true` actually test agent output
- TECHNICAL.md Stratum claims match reality
- `cargo audit` blocks CI on critical advisories
- Cosign signing blocks release on failure
