# Workorder 20.6.0 — TUI & UX Improvements

## Source

Cross-review §4.6.

## Problem

The TUI is ahead of most CLI agents on event loop engineering and approval UX,
but behind on mouse support, themes, inline images, and state management.

## Targets

### U1. Decompose `AppState` from 68 fields (HIGH)

- `AppState` has 68 fields, not 44+ as `state.md:86` claims
- Borrow-checker workarounds already in render path (`mem::take` dance at
  `mod.rs:986-999`)
- Comments already group fields into logical sub-structs
- **Fix:** Split into `ApprovalState`, `SearchState`, `DaemonState`,
  `RenderCache`, `GenerationState`. Keep `AppState` as top-level struct holding
  sub-structs. Update `state.md` to reflect actual count.

### U2. Mouse support (MEDIUM)

- No mouse support — table-stakes for a 2026 TUI
- Scrolling, tab selection, approval buttons all beg for mouse input
- **Fix:** Add `crossterm` mouse capture on startup. Map scroll wheel to
  chat/list scroll. Map click to button/focus events. Keep keyboard-first.

### U3. Themes (LOW)

- No theme support — dark mode only
- **Fix:** Add a `Theme` struct with colors. Provide 2-3 built-in themes
  (dark, light, solarized). Load from config. Low priority but high user impact.

### U4. Inline image rendering (LOW)

- `Tag::Image` styled as magenta italic text — multimodal is half-built
- **Fix:** Use `ratatui`'s inline image protocol (Sixel/Kitty/IT2) for terminal
  image rendering. Fall back to magenta italic text for unsupported terminals.

### U5. F6 "Threads" tab overclaims (LOW)

- `state.md` and TUI tab label say "Threads" but it's a session-picker list,
  not live thread state
- **Fix:** Either rename to "Sessions" or implement actual thread state display.

### U6. `lessons.md:21` is stale (LOW)

- Claims F1–F6 tabs are MISSING; they're fully implemented
- Will cause a worker to re-implement shipped features
- **Fix:** Update `lessons.md` to reflect reality. Covered in WO 20.0.8 G7.

### U7. Syntax highlighting quality (LOW)

- Hand-rolled syntax highlighting for code blocks
- Defensible for binary size but medium quality
- **Fix:** Evaluate `syntect` (already a dep via `bat`) or `tree-sitter`
  highlighting. If binary size impact is >100KB, keep hand-rolled.

## Verification

- `AppState` decomposed into sub-structs, total field count unchanged
- Mouse scroll works in chat view
- Theme switchable via `/theme` command or config
- `lessons.md` accurately reflects shipped features
