# Workorder 20.7.0 — Bench & Eval Improvements

## Source

Cross-review §3.4 + review #2 (bench reports) + review #3 (priorities).

## Problem

5 of 31 bench tasks verify against setup files, not agent output. The bench
system needs reports, not just PASS/FAIL. Execution replay would make debugging
regression runs tractable.

## Targets

### B1. Fix 5 rigged bench tasks (HIGH)

- `use_draw_render.toml` → `file_contains` on `diagram.td.json` (setup file)
- `use_workflow_run.toml` → `test -f .kf-code/workflows/feature.json` (setup file)
- `use_budget_check.toml` → `file_contains` on `config.toml` (setup file)
- `use_stratum_compress.toml` → `file_contains` on `data/big.txt` (setup file)
- `use_lsp_query.toml` → `file_contains` on `src/lib.rs` (setup file)
- An agent doing literally nothing scores 100% on these tasks
- **Fix:** Add `requires_model = true` and verify real agent output. The agent
  must call the tool and the verify must check the tool's output, not the
  setup file. This test would have caught P0-1 (plugin env-var mismatch).

### B2. Benchmark reports with metrics (MEDIUM)

- Currently: PASS/FAIL per task
- Reviewer wants:
  ```
  Task           Success    Tokens    Time    Retries    Cost
  Rename Fn      98%        4,231     11s     1.0         $0.04
  Borrow Error   94%        6,120     18s     1.4         $0.07
  Budget Ch.     90%        2,850     13s     1.2         $0.02
  ```
- **Fix:** Extend `kf-bench` to emit per-task metrics: token count, wall time,
  retry count, cost, success rate. Output as markdown table + JSON. Include in
  CI artifacts.

### B3. Execution replay (MEDIUM)

- ADR-0039 exists for replay + time-travel but not implemented
- `kf replay session-1234` should replay: prompt, retrieved context,
  compression, provider, verification, edits
- **Fix:** Implement session replay from NDJSON logs. `kf replay <session>`
  shows the full turn-by-turn execution. `kf replay --diff` shows only edits.
  `kf replay --step N` jumps to step N.

### B4. Non-file tool durations always 0 (LOW)

- `turn.rs:991` records tool duration but non-file tools always show 0
- Can't profile slow tools in bench reports
- **Fix:** Record actual wall-clock duration for all tool calls. Include in
  bench metrics.

### B5. `adr_0010` drift test is red (LOW)

- `crates/kf-budget-core/tests/cost_reporting_spec_drift.rs:244` expects
  emission-site literals that don't exist
- Both ADR and impl moved on
- **Fix:** Update test expectations to match current ADR content, or mark ADR
  as superseded.

### B6. `bundled_node_sdk` test silently no-ops (LOW)

- `src/session/plugin_tools/tests.rs:625` — not `#[ignore]`'d, silently
  returns on missing node/SDK → passes without testing anything
- **Fix:** Mark `#[ignore]` or add a `requires_node` gate.

## Verification

- All 31 bench tasks verify against agent output, not setup files
- `kf bench report` produces markdown table with tokens/time/cost per task
- `kf replay <session>` shows turn-by-turn execution
- `adr_0010` drift test passes
