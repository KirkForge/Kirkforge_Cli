# Workorder 21.11 — Plugin Real-Rebuild: Budget / Stratum / SDK (+ draw/video yeeted)

## Status: Planned

## Problem

Owner directive: **yeet `kf-draw` + `kf-video`** (the scope-creep crates the review
flagged as clutter), and **rebuild the 3 keeper plugins properly** — `budget`,
`stratum`, `plugin-sdk`. This workorder is grounded in a forensic comparison of
the 3 original plugin repos (`KirkForge-Plugin` = SDK, `KirkForge-Plugin2` =
Stratum, `KirkForge-Plugin3` = Budget) against the integrated crates, done
2026-08-07, with `file:line` evidence on both sides — not narrative.

The comparison corrected the premise, and the correction matters (it is what
prevents an 8th botched attempt):

- **Stratum** is the genuine skeleton. `CompressionPipeline` is a unit struct
  (`pub struct CompressionPipeline;`) whose `run()` is identity-or-offload; the
  host never registers a transform. From the CLI it compresses nothing. BUT the
  *original* `KirkForge-Plugin2` CLI **also** ran an empty pipeline
  (`register_content_transform` appears only in its `examples/`, doc-comments,
  and `#[test]` blocks — never called in production). So nothing working was
  stripped; the real transforms (the host's `src/shared/minify` tree-sitter
  module, 12 langs) were never wired in either version. **Stratum needs a real
  build, not a restore.**
- **SDK** did NOT shrink — it grew (sdk 649→1120, host 1439→2571) and load-time
  trust filtering got *stronger*. It is not a skeleton. It has specific real
  defects: the per-call defense-in-depth trust check was deleted, the signature
  model silently changed (Ed25519+multi-key → minisign+single-key) with a wrong
  "contract unchanged" claim in ADR-057, and the two plugin load paths use
  inconsistent `TrustPolicy`. **SDK needs targeted fixes + doc reconciliation.**
- **Budget** is the *complete* one (review line 100: "kf-budget is the complete
  one"). 5.7K LOC of real modules; budget slicing works (P0-5 FIXED). Its gaps
  are unfinished host adapters (only Claude Code wired) and the redundant
  standalone CLIs. **Budget needs finishing + trimming, not a rebuild.**
