# Workorder 21.3 — Stratum Compression: Register Real Content Transforms

## Status: Planned

## Problem

The branded "Stratum compression pipeline" is an empty harness: offload-only.
`register_content_transform` has **zero callers**; every production site runs
`CompressionPipeline::new()` empty. The real minification happens in an
unbranded `minify` module (real tree-sitter AST minification for 12 file
types). `TECHNICAL.md:383-389` overclaims "content-type-specific transforms."
P0-4 fixed the offload *retrieval* (markers now resolve); this fixes the
*emptiness*. This supersedes WO 20.0.9 §S6's "downgrade the claims" option —
**owner direction is to make the claims true by finishing the feature.**
