# Workorder 21.4 — LLM Adapter Gaps

## Status: Planned

## Problem

The adapter layer is Tier-1 solid (Anthropic-direct + OpenAI-compat + Ollama;
Bedrock+Vertex now wired; cache-breakpoint cap-4 enforced; extended-thinking
emitted; `max_tokens` configurable). But several still-open gaps keep it behind
opencode/Cursor: `tool_choice` *forcing* has zero callers, JSON-schema
structured output is absent, native Gemini/Azure/Mistral/Groq/xAI first-party
adapters are missing, keychain is stubbed to `None`, and AWS profile/SSO auth
is unimplemented. Bedrock/Vertex plumbing is real but its tests are weak
(name-only assertions).

## Source

Review reality-check §4.2 + scorecard "LLM adapters 7.0" row. P0-2 (Bedrock/
Vertex unwirable) is FIXED (excluded except for the test-hardening remnant).
