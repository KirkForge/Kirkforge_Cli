# Workorder 21.5 — Tools & MCP Surface Gaps

## Status: Partial

## Problem

The tool surface is strong where it's built (`edit_file`, `bash` deny-list,
`web_fetch` SSRF, `read_image`, `todo`, `task`), but several daily-friction
gaps remain: `grep` defaults to literal with no ripgrep, `bash` has no PTY/
streaming (a disclosed ponytail deferral), MCP resources/prompts are
implemented at the wire layer but not surfaced to the agent (and a false
`UNSUPPORTED_CAPABILITIES` signal is still sent), `replace_all`/multi-edit is
absent, `computer_use` has open dedup debt (M21), HTML→markdown is regex
tag-stripping, and tool schemas are hand-written with no args-vs-schema
validation.

## Source

Review reality-check §4.3 + scorecard "Tools & MCP 7.0" row. MCP *strategy*
(bespoke-vs-MCP migration) lives in 21.10; this workorder owns the MCP
*capability surface* (resources/prompts/sampling/roots) that 21.10's migration
consumes.

## Targets

### 21.5-R1 — `grep`: ripgrep backend / regex-by-default (HIGH · est M · dep: —)

**Reality check (`a870571`):** "`grep.rs:35,83-90` compiles `regex::Regex` when
`regex=true`. Literal remains default; **ripgrep still absent**."

**Scope:** `src/tools/grep.rs`, optional `rg` shell-out path, tool description.

**Success (done):**
- `grep` uses `rg` when available (fast, respects gitignore, real regex by
  default) with a graceful fallback to the in-process regex matcher when `rg`
  is absent; regex is no longer gated behind an opt-in flag for the `rg` path.
- A test asserts `fn\s+\w+`-style patterns return regex-matched results without
  an explicit flag, and that absence of `rg` degrades cleanly (no panic).

**Failure (regression / not-done):**
- Still literal-substring-by-default with `rg` on PATH = FAIL.
- `rg` absent → panic or silent no-results = FAIL.

**Defer:** none.

### 21.5-R2 — `bash`: PTY + streaming output (HIGH · est L · dep: —)

**Reality check (`a870571`):** "`bash.rs:13-17` explicitly documents the
`portable-pty` deferral. **STILL TRUE** (ponytail-deferred)." `npm login`,
`gh auth login`, `python -i`, password prompts hang until timeout.

**Scope:** `src/tools/bash.rs`, `src/tools/bash_runner/mod.rs:397-479`, the
`portable-pty` dep (evaluate binary-size cost against the release profile).

**Success (done):**
- `bash --interactive` (or an auto-detected interactive mode) supports PTY +
  streaming output + stdin, so interactive commands do not hang.
- A test asserts a password-prompt-style command completes (does not time out)
  under the new path; non-interactive default preserved.

**Failure (regression / not-done):**
- Interactive commands still hang = FAIL.
- Non-interactive default path regresses (slower / behavior change for the
  common case) = FAIL.

**Defer:** DEFER-215-R2 — this is the one item in WO 21 with a pre-existing
disclosed ponytail deferral (`bash.rs:13-17`). If the `portable-pty` binary-
size cost is unacceptable for the release profile, defer is acceptable BUT
must keep the inline `bash.rs:13-17` disclosure + a PONYTAIL-DEBT entry naming
the ceiling; silent retention of the hang is FAIL.

### 21.5-R3 — Surface MCP resources/prompts to the agent + drop false `UNSUPPORTED_CAPABILITIES` (MEDIUM · est M · dep: —)

**Reality check (`a870571`):** "`list_resources`/`resources/read`/
`list_prompts`/`prompts/get` implemented at wire layer; **but
`UNSUPPORTED_CAPABILITIES=[\"resources\",\"prompts\",…]` still sent in init**,

**Scope:** `src/session/mcp_client/mod.rs` (init capabilities +

  agent surface.

**Failure (regression / not-done):**
- Wire layer implemented but still not surfaced to the agent = FAIL.
- False `UNSUPPORTED_CAPABILITIES` still sent = FAIL.

**Defer:** none. (21.10-R1 depends on this capability existing.)

### 21.5-R4 — MCP `sampling/createMessage` + `roots/list` (LOW · est M · dep: 21.5-R3)

**Reality check (`a870571`):** "`sampling/createMessage` + `roots/list` remain
unimplemented."

**Scope:** `src/session/mcp_client/mod.rs`, sampling handler (server requests
the agent's model), roots exposure.

**Success (done):**
- `sampling/createMessage` is handled (an MCP server can request a model
  completion) and `roots/list` exposes the agent's workspace roots; both gated
  behind user approval (security boundary).
- Tests assert both round-trip; a test asserts sampling is denied without
  approval.

**Failure (not-done / regression):**
- Both still absent = FAIL.
- Sampling allowed without an approval gate = FAIL (security regression).

**Defer:** DEFER-215-R4 — sampling has a real security surface; if approval UX
isn't ready, defer is acceptable with a tracking ID + a startup warning when a
server requests sampling, but roots (read-only, lower risk) should still ship.

**Reality check (`a870571`):** "No `replace_all` / multi-edit — refactors that

- `replace_all` with zero matches silently succeeds = FAIL (must error).

### 21.5-R8 — Tool schema validation (args vs `def().parameters`) (LOW · est S · dep: —)
