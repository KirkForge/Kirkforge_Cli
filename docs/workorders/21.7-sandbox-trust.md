# Workorder 21.7 — Sandbox & Trust Hardening

## Status: Partial

## Problem

The verification/budget/sandbox axis scores 7.5 — the verifier→model loop is
the unique differentiator and the budget guard now actually slices. But the
*default* sandbox is rlimits-only (no OS isolation, no egress/fs control) while
codex-cli ships seatbelt/landlock by default; seccomp is deferred (ADR-054);
missing sandbox config only warns (fail-open); there's no diff-review-before-
apply; cosign release signing is best-effort; plugin signature verification is
off by default with zero signed plugins shipping; and the `SandboxEnforcer`
name overclaims.

## Targets

### 21.7-R1 — Default OS sandbox: seatbelt (macOS) + landlock (Linux) (HIGH · est L · dep: —)

**Reality check (`a870571`):** "Default non-Docker bash path = no sandbox.
`src/session/executor/sandbox.rs` (41 lines) is **not a sandbox** — it's
`PathGuard` + `DenyList` + `ReadGate` file-access control. **codex-cli ships
seatbelt/landlock by default; kf-code is materially behind here.**" This
delivers filesystem isolation + network egress control on the default path (the
two sibling gaps the review names).

**Scope:** `src/session/executor/sandbox.rs`, a seatbelt sandbox-exec profile
(macOS) and/or landlock (Linux) integration, default-on gating, escape hatch
for trusted dirs.

**Success (done):**
- On macOS the default bash path runs under a seatbelt profile; on Linux under
  landlock — providing filesystem write confinement + network egress blocking
  without `--docker`/`--harden`.
- Tests assert (a) a write outside the workspace is blocked, (b) a `curl
  evil.com` egress is blocked, on each supported OS (gated where the kernel
  feature is absent).

**Failure (regression / not-done):**
- Default path still rlimits-only = FAIL.
- Sandbox added but silently disabled when the OS feature is missing (no
  warning/refusal) = FAIL (see 21.7-R5).

**Defer:** DEFER-217-R1 — Windows has neither seatbelt nor landlock; a Windows
path may defer to the existing Docker mode, disclosed with a tracking ID. mac +
Linux must ship. Pure rlimits retention = FAIL.

### 21.7-R2 — seccomp syscall filter (ADR-054) (MEDIUM · est L · dep: 21.7-R1)

**Reality check (`a870571`):** "seccomp explicitly deferred (ADR-054) —
`libseccomp` breaks the static-binary story."

**Scope:** `src/session/executor/sandbox.rs`, seccomp integration (evaluate
the static-binary tradeoff ADR-054 names), ADR-054 status update.

**Success (done):**
- A seccomp filter blocks dangerous syscalls on the Linux default path (or a
  documented, ADR-backed decision to keep it deferred with the tradeoff
  quantified); ADR-054 status reconciled with the decision.
- A test asserts a blocked syscall is rejected.

**Failure (not-done / regression):**
- ADR-054 still says "deferred" with no new evidence/decision = FAIL (stale
  deferral with no ceiling update).
- seccomp added but breaks the static binary with no documented mitigation =
  FAIL.

**Defer:** DEFER-217-R2 — deferring seccomp is acceptable IF 21.7-R1 (landlock)
ships and ADR-054 is updated to reflect the layered mitigation; disclosed with
a tracking ID, not silent.
