# Workorder 21.8 — TUI & Agent-Loop Gaps

## Status: Done (AppState decomposition + themes deferred)

## Problem

The agent loop is mechanically sound (parallel dispatch, atomic undo,
per-result checkpointing, honest cost tracking, sound cancellation) and the TUI
has real strengths (render-on-dirty, unified + side-by-side diff approval,
CommonMark, 30 slash commands). But the §4.1/§4.6 gaps that remain are the ones
that age worst: the `AppState` God object (68 fields, the #1 maintainability
risk), a doom-loop that is detected but never remediated, and a TUI surface with
no real themes or inline-image rendering. Several items the review named as open
have **drifted** since `a870571` (multi-turn subagents, the background-task
semaphore, scroll-wheel mouse, and the max-tokens continuation now exist) — per
the overview's cross-cutting rule those are re-verified here and scoped down to
the work that is actually left (tests, caps, configurability, the remaining
slices), not re-implemented from scratch.

## Source

Review reality-check §4.1 + §4.6 + scorecard "Agent loop 7.0" / "TUI/UX 7.5"
rows. Several original claims are re-verified STALE below (code moved ahead of
the snapshot); the success criteria reflect current HEAD, not the snapshot.
