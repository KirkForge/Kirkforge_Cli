# Workorder 24.8 — Audit `tracing::debug!` Calls Against AGENTS.md §5

## Problem

AGENTS.md §5 states: "No debug spam (`println!`, `eprintln!`, `dbg!`, `tracing::debug!` left on in committed code) in committed code." The review (#38, also §4.9) identifies that `tracing::debug!` calls were reduced from 47 to 23, but 23 remain. Each one must be audited: either it's a legitimate debug-level log that should stay (with a documented reason), or it's debug spam that should be removed, converted to `tracing::trace!`, or gated behind a feature flag.

## Root cause

23 `tracing::debug!` calls exist in `src/` committed code. AGENTS.md §5 forbids debug spam in committed code. The calls are in:
- `src/main/turn_events.rs:51` — "failed to flush stdout token"
- `src/main/handle_replay.rs:134,137` — "failed to disable raw mode", "failed to leave alternate screen"
- `src/daemon/client.rs:297,323,342,358` — "daemon not running" variants
- `src/tui/mod.rs:78,82,85,295,298,301,339,345,348` — terminal/daemon lifecycle messages
- `src/tui/daemon_events.rs:43,51,92` — daemon connection messages
- `src/session/mcp_client/spawn.rs:32` — MCP stderr forwarding
- `src/session/mcp_client/manager.rs:284,331` — MCP resource/prompt failures
- `src/shared/metrics.rs:398` — "no metrics path available"

## Scope

1. Every `tracing::debug!` call in `src/` — audit and convert or remove
2. `AGENTS.md` — document the allow-list if any `tracing::debug!` calls are retained

## Plan

### 24.8-R1 — Audit and classify all 23 `tracing::debug!` calls

For each call, classify as:
- **Remove**: Debug spam that provides no value in production (e.g., "daemon not running" messages that fire on every startup when daemon isn't configured).
- **Convert to `tracing::trace!`**: Useful for deep debugging but too noisy for `debug!` level (e.g., MCP stderr forwarding, metrics path).
- **Convert to `tracing::warn!`**: Error-adjacent messages that should be visible (e.g., "failed to disable raw mode" is a terminal state issue, not debug).
- **Retain as `tracing::debug!`**: Legitimate debug-level messages with a documented reason (add a comment explaining why it stays).
