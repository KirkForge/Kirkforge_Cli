# Workorder 25.1 — Fast Test Gate Split

## Status: Planned

## Problem

AGENTS.md §4 requires running `cargo test --locked --workspace --no-fail-fast` before every commit. This takes 10+ minutes. The result: agents skip the gate, developers skip the gate, regressions land. The gate that was supposed to catch problems has become the problem.

## Root cause

There is no tiered gate. Every commit runs every test — unit, integration, ignored, and known-broken — with the same weight. There's no "quick smoke test" that catches 80% of regressions in 30 seconds.

## Scope

1. `scripts/test-fast.sh` — new script
2. `scripts/test-full.sh` — new script
3. `AGENTS.md` — gate section update
4. `scripts/ci-local.sh` — wire in the fast gate as default

## Plan

### 25.1-R1 — Create `scripts/test-fast.sh` (HIGH · est S · dep: —)

**Reality check:** `scripts/ci-local.sh` already exists and runs the full gate. The fast gate is a subset: unit tests only, no integration tests, no `#[ignore]` tests, parallel threads.

**What to do:**
- Create `scripts/test-fast.sh` that runs:
  ```
  cargo test --locked --workspace --lib --bins --no-fail-fast -- --skip integration --skip ignored
  ```
  Adjust the skip filter once the exact test naming convention for integration tests is confirmed (check `scripts/run-integration-tests.sh`).
- Target: ~30 seconds on a warm cache.
- The script should exit non-zero on test failure (no `|| true`).
- Add `--test-threads=N` where N defaults to `$(nproc)` (capped at 8 to avoid thrashing).

**Scope:** `scripts/test-fast.sh` (new).

**Success criteria:**
- `scripts/test-fast.sh` exists and is executable.
- Runs only unit/lib tests, skips integration and ignored tests.
- Completes in under 60 seconds on warm cache.

**Failure criteria:** Script doesn't exist or exits 0 on failure.

**Estimate:** S

**Defer note:** none.

### 25.1-R2 — Create `scripts/test-full.sh` (MEDIUM · est S · dep: —)

**Reality check:** The full gate is what `scripts/ci-local.sh` already does, but having a dedicated test-only script makes CI wiring cleaner and gives developers a single command for "run everything."

**What to do:**
- Create `scripts/test-full.sh` that runs the full test suite:
  ```
  cargo test --locked --workspace --no-fail-fast
  ```
- This is the CI gate, not the local gate.
- Include a note in the script header: "CI-only. Use test-fast.sh for local development."

**Scope:** `scripts/test-full.sh` (new).

**Success criteria:**
- `scripts/test-full.sh` exists and is executable.
- Runs the full workspace test suite.
- Documented as CI-only.

**Failure criteria:** Script doesn't exist or exits 0 on failure.

**Estimate:** S

**Defer note:** none.

### 25.1-R3 — Update AGENTS.md gate section (HIGH · est S · dep: R1, R2)

**Reality check:** AGENTS.md §4 is the contract agents follow. Changing it changes behavior. The current gate requires the full suite before every commit — this is the root cause of gate-skipping.

**What to do:**
- Update AGENTS.md §4 Gates section to:
  - **Local gate (fast):** `scripts/test-fast.sh` + `cargo clippy --all-targets -- -D warnings` + `cargo fmt --check` + `cargo check --workspace --all-targets`. Target: under 2 minutes total.
  - **Pre-merge gate (full):** `scripts/test-full.sh` + full clippy + fmt + check + `cargo test -p kf-budget-core --test adr_xref_drift`. Required before pushing to `dev`.
- Keep the full gate as a requirement, but relegate it to "before merge," not "before every commit."

**Scope:** `AGENTS.md`.

**Success criteria:**
- AGENTS.md §4 lists fast gate as the local default.
- Full gate is required before merge/push to `dev`.
- No ambiguity about when each gate applies.

**Failure criteria:** AGENTS.md still requires full test suite before every commit.

**Estimate:** S

**Defer note:** none.
