# Workorder 25.16 — Coverage Push: `src/session` >75% (carry-forward of WO 24.6)

## Status: Planned

## Priority: P2 — depends on WO 25.4 (coverage baseline tooling)

## Problem

WO 24.6 was deferred because `cargo llvm-cov` was not installed. The 75%
target was never reached for `src/session` — the deepest, most critical
module (executor loop, budget slicing, compaction, verifier bus).
Coverage gaps hide regressions in the most safety-relevant code paths.

- state.md "Deferred items" → "24.6-R1..R5".

## Requirements

### R1 — Install `cargo llvm-cov` + baseline

- Add `cargo llvm-cov` and the `llvm-tools-preview` rustup component to CI.
- Measure baseline coverage per `src/session/` subdirectory.
- Record baseline numbers in this WO's Status section when complete.
- **Depends on WO 25.4** (coverage baseline tooling).

### R2 — Executor loop tests (6 scenarios)

- Turn-start (initial message, system prompt assembly).
- Tool-call dispatch (parameter validation, adapter routing).
- Doom-loop circuit breaker (`observe_tool_outcome` hit accounting).
- Multi-turn continuation (max-continuation cap from WO 23.9).
- Plan-mode entry/exit (incl. the `cached_tokens` reset path from 25.12).
- Cost-budget trip (turn abort on budget exhaustion).

### R3 — Budget slicing tests (4 scenarios)

- Slice threshold trip (context size triggers a slice).
- Slice message selection (which messages get compacted).
- Slice ordering (slice preserves logical conversation order).
- Post-slice context integrity (no dropped tool-call/tool-result pairs).

### R4 — Compaction tests (5 scenarios)

- Trigger threshold.
- Summary generation (LLM compaction call).
- Tail preservation (verifier-findings pinned at `compaction.rs:247`).
- Multi-pass compaction (compaction triggers again on a long session).
- Compaction-then-resume (turn continues correctly after compaction).

### R5 — Verifier bus tests (4 scenarios)

- Event broadcast (verifier sees every tool result).
- Verifier registration (dynamic add/remove).
- Verdict aggregation (multiple verifiers, mixed Pass/Fail).
- Bus-disconnect mid-turn (verifier dropped mid-turn does not panic).

## Success criteria

- `src/session` coverage ≥75% per `cargo llvm-cov` (line + region).
- Each R2-R5 scenario has at least one passing test exercising the
  behavior (not just the lines).
- Coverage regression gate (WO 25.4) enforces the new baseline.
- Baseline numbers recorded in this WO.

## Failure criteria

- Tests added to game the coverage metric (trivial asserts that
  exercise lines without testing behavior — AGENTS.md §6 violation).
- Coverage gate lowered to make the number pass.
- Baseline measured only on happy paths (error branches uncovered).
- Tests `#[ignore]`-marked to keep the suite green (AGENTS.md §4 violation).
