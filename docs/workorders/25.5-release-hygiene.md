# Workorder 25.5 — Release / Install / Build / CI-Local Script Hygiene

## Status: Planned

## Priority: P0 — release correctness

## Problem

The Plugin3→kf-budget-core and Stratum→kf-compress-core migration was completed in code, but 5 active scripts still reference the old artifact graph. 17 stale references across 5 files. Some cause real runtime failures (release.yml copies non-existent binaries, install.sh tries to install ghosts).

**Rule being violated:** No active script may reference a removed crate/binary/path.

## Source

External audit (release-readiness review). Confirmed by `grep` across `scripts/`, `.github/workflows/`, `install.sh`, `README.md`.

## Requirements

### R1: Fix `scripts/install.sh`

**Lines 92, 134.** Current: `for bin in kf-code kfd plugin3 stratum kf-code-video`.

- Remove `kfd`, `plugin3`, `stratum`, `kf-code-video` from the install loop.
- Only `kf-code` is a binary target in the current workspace.
- Update the echo on line 134 to match.
- Gate: `bash -n scripts/install.sh` (syntax check).

### R2: Fix `scripts/build-all.sh`

**Lines 13-17, 71.** Comments reference `kfd`, `kf-code-video`, `stratum`, `plugin3` as build outputs. Line 71 references `npm/kf-code-plugin` (actual dir: `npm/kf-plugin`).

- Remove stale binary comments (lines 13-16).
- Fix npm path (line 71): `npm/kf-code-plugin` → `npm/kf-plugin`.
- Gate: `bash -n scripts/build-all.sh`.

### R3: Fix `scripts/ci-local.sh`

**Lines 44, 46, 48, 77.** Lines 44-48 reference `npm/kf-code-plugin`. Line 77 runs `cargo test -p plugin3-core --test adr_xref_drift` — crate doesn't exist (actual: `kf-budget-core`).

- Fix npm path references (lines 44, 46, 48): `npm/kf-code-plugin` → `npm/kf-plugin`.
- Fix crate reference (line 77): `plugin3-core` → `kf-budget-core`.
- Gate: `bash -n scripts/ci-local.sh` + `cargo test -p kf-budget-core --test adr_xref_drift`.

### R4: Fix `.github/workflows/release.yml`

**Lines 174, 188.** `bins=(kf-code plugin3 stratum)`. Windows step copies `dist\plugin3.exe` and `dist\stratum.exe` which don't exist.

- Line 174: `bins=(kf-code)` only.
- Line 188: Remove `dist\plugin3.exe` and `dist\stratum.exe` from `Compress-Archive`.
- Gate: Read release.yml and verify no `plugin3` or `stratum` binary references remain.

### R5: Fix README.md stale references

**Lines 38, 41-42.** Line 38 mentions "Plugin3". Line 41 says "31 coding tasks" (actual: 30 `.toml` files). Line 42 links to `KIRK-BENCH.md` which doesn't exist.

- Line 38: "Plugin3" → "Budget" (or "kf-budget-core").
- Line 41: Verify count; if 30 `.toml` files, change to "30 coding tasks".
- Line 42: `[KIRK-BENCH](KIRK-BENCH.md)` → `[Benchmarks](docs/TECHNICAL.md#benchmarks)` or appropriate anchor.

## Success criteria

- Zero references to `plugin3`, `kf-code-video`, `kfd` as binary targets in any active script or CI file.
- Zero references to `npm/kf-code-plugin` in any script.
- `scripts/ci-local.sh` runs the correct `kf-budget-core` drift test.
- Release workflow packages only `kf-code`.
- Install script installs only `kf-code`.
- No broken links in README.

## Failure criteria

- Fix removes a reference but the replacement is also wrong.
- A stale reference in a script causes a runtime failure that wasn't there before.
