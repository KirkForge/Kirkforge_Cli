# Workorder 25.8 — Historical Residue Cleanup

## Status: Done (R4 deferred)

## Priority: P2 — maintainability

## Problem

The Plugin3→kf-budget-core migration (WO 12/18/19) moved the code but left 26+ files with stale references to the old crate names, binary names, and directory paths. Historical references in ADRs and completed workorders are legitimate. But references in active source, config, scripts, and CI are release-readiness debt.

**Enforcement rule:** No active script or source file may reference a removed crate/binary/path. Historical references in `docs/archive/`, completed ADRs, and workorders are fine.

## Source

External audit: "You've folded the old systems into the new one. Now the repository needs to stop remembering that they used to be separate."

## Requirements

### R1: Audit all `plugin3` references in non-historical files

```
grep -rn 'plugin3' --include='*.rs' --include='*.toml' --include='*.sh' --include='*.yml' src/ crates/ scripts/ .github/ Cargo.toml
```

Classify each hit:
- **HISTORICAL (keep):** ADRs in `docs/adr/`, workorders in `docs/workorders/`, CHANGELOG entries, git history
- **ACTIVE (fix):** source code, scripts, CI configs, Cargo.toml

Fix all ACTIVE hits. For each, determine the correct current name and update.

### R2: Audit `kfd` references in non-historical files

Same approach. `kfd` was the old daemon binary — replaced by the `kf-code` binary's daemon mode (or removed entirely).

### R3: Audit `kf-code-video` / `kf-code-draw` references

Same approach. Draw/video were yeeted in WO 21.1. Any references in active code should be removed or gated behind a feature flag that no longer exists.

### R4: Create an enforcement gate

Add a CI check or pre-commit hook that greps active source for known-dead names:
```
grep -rn 'plugin3' src/ crates/ scripts/ .github/ && echo "ERROR: dead crate reference found" && exit 1
```

This prevents the drift from recurring. Exclude historical docs (`docs/adr/`, `docs/workorders/`) explicitly.

## Success criteria

- Zero references to `plugin3`, `kfd`, `kf-code-video`, `kf-code-draw` in `src/`, `crates/`, `scripts/`, `.github/`, root `Cargo.toml`.
- Enforcement gate prevents re-introduction.
- Historical references in ADRs/workorders preserved (they document the migration).

## Failure criteria

- Historical references deleted (losing migration history).
- Enforcement gate has false positives (blocking legitimate references).

### R5: Archive `editors/vscode/` (dead VS Code extension)

`editors/vscode/` is 16 files (9 `.ts`, package.json, tsconfig) implementing a VS Code extension with chat panel, diff view, TODO panel, and LSP bridge. It has zero references from Rust code, zero CI pipeline, zero build/install integration. Last commit was 2026-07-22 (pre-rename). The extension communicates with kf-code over NDJSON but was never shipped as part of the release flow.

- Move `editors/vscode/` to `docs/archive/editors/vscode/` (preserving git history if needed, or just delete if there's no interest in reviving it).
- Alternatively: move to a separate repo if there's intent to revive it as a standalone extension.
- Gate: `grep -rn 'editors/vscode' src/ crates/ scripts/ .github/` returns zero hits.
