# Workorder 25.9 — Dead Code & Non-Rust Lint Stub Cleanup

## Status: Planned

## Priority: P1 — AGENTS.md §5 ("no dead code") violation

## Problem

Multiple `#[allow(dead_code)]` items survive in production with zero callers,
and the verifier's non-Rust lint path silently returns `Verdict::Skipped`
behind a `ponytail:` "unimplemented" note. The dead code violates the
"no dead code" rule; the lint stub silently downgrades verification for
Python/JS/TS files (the model is told "verified" when nothing happened).

## Source

Audit pass (post-WO-22 verification). Each item cites the surviving site:

- `src/shared/mod.rs:201-205` — `ToolChoice::Specific` variant.
- `src/adapters/anthropic.rs:328`, `src/adapters/mod.rs:798` — match arms.
- `src/session/router.rs:262` (`classify`), `:171` (`classify_with_llm`).
- `src/session/adapter_swap.rs:66` — production calls `classify_local` only.
- `src/session/verifier/bus.rs:225-226` — `format_verdict_report`, `#[allow(dead_code)]`, 8 unit tests.
- `src/tui/commands/persona.rs:51-56` — `PersonaHandle` fields `kind`, `task`, `fork_id`, all `#[allow(dead_code)]`.
- `crates/kf-budget-core/src/budget.rs:207` — `estimate_tokens_heuristic`, one test caller, `#[deprecated(since = "TBD")]`.
- `src/session/verifier/lint.rs:84-92` — Python/JS/TS branch returns `Verdict::Skipped` with `ponytail:` note.

## Requirements

### R1 — Re-verify and remove `ToolChoice::Specific` + `set_tool_choice`

**Reality check:** WO 22.7-R2 previously closed this as "not over-engineering —
wired into Bedrock/Vertex/OpenAI-compat forced-tool routing." The current
audit found zero production callers. These conflict.

- Re-grep ALL call sites of `ToolChoice::Specific` and `set_tool_choice`.
- If genuinely dead (no production caller routes a forced tool through it):
  delete the variant, the trait method, and its 3 impls.
- If alive in any adapter path: KEEP, and replace this WO line with "closed
  as not-dead — evidence: <file:line of real caller>" so the next audit
  doesn't re-flag it.

### R2 — Remove or wire `router::classify` and `router::classify_with_llm`

- Both are test-only callers; production uses `classify_local`.
- Either delete both + their tests, OR plumb `classify_with_llm` into
  `adapter_swap.rs` if LLM-based routing is a desired feature.
- Do NOT leave test-only code in the production module behind `#[allow(dead_code)]`.

### R3 — Remove or wire `format_verdict_report`

- Pub fn with 8 unit tests, 0 production callers, `#[allow(dead_code)]`.
- Either delete fn + tests, or wire into a TUI `/verify report` command
  (the function clearly exists to render a report — give it a UI).

### R4 — Trim `PersonaHandle` dead fields

- `kind`, `task`, `fork_id` are all `#[allow(dead_code)]`.
- Either populate them where `PersonaHandle` is constructed, or delete.

### R5 — Remove `estimate_tokens_heuristic`

- Delete the function and its `#[deprecated(since = "TBD")]` placeholder.
- Replace the one test caller with a call to the real tokenizer path
  (shipped per WO 21.6-R3 "real tokenizer").
- The placeholder version string `"TBD"` must not survive.

### R6 — Honestly handle non-Rust verifier linting

- `src/session/verifier/lint.rs:84-92` returns `Verdict::Skipped` for Python/JS/TS.
- Option A: shell out to `ruff` (Python), `eslint`/`tsc` (JS/TS), gated on
  binary presence in `PATH`. Verdict becomes `Pass`/`Fail` with diagnostic text.
- Option B: replace the `ponytail:` note with a `ceiling:` note that
  explicitly documents non-Rust linting is out of scope and the `Skipped`
  verdict is intentional and model-visible. No silent skip.

## Success criteria

- `cargo clippy --workspace --all-targets -- -D warnings` passes with all
  listed `#[allow(dead_code)]` items removed (or restored to real use).
- No `#[deprecated(since = "TBD")]` placeholder remains in the codebase.
- Non-Rust lint path either runs a real linter or carries a `ceiling:` note
  (no bare silent `Skipped`).
- `cargo test --workspace` green.
- Every R-item either shipped or re-deferred with explicit AGENTS.md §11
  disclosure (R1 may close as "not-dead" with cited evidence).

## Failure criteria

- R1 deletes `ToolChoice::Specific` and breaks Bedrock/Vertex forced-tool
  routing — regression. Must re-verify call sites first.
- R6 silently keeps `Skipped` without the `ceiling:` note.
- Tests deleted to make the dead code "look unused" (AGENTS.md §6 violation).
- R1 closed as "not-dead" without a file:line evidence citation.
