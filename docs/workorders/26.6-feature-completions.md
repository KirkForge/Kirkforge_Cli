# Workorder 26.6 — Feature Completions (sessions_dirty, persona, non-Rust lint)

## Status: R3 done; R1, R2 pending

## Priority: P1

## Problem

Three deferred P1 items from state.md each have clear root causes and
scoped fixes. None requires new architecture — each follows an existing
pattern already proven in the codebase.

## Source

state.md "Deferred items" — 25.11-R2, 25.17-R1-remaining, and the non-Rust
linting gap identified in cross-review.

## Requirements

### R1 (25.11-R2) — sessions_dirty refresh

- Daemon `sessions-list` shows stale session state after foreground edits.
- Mirror the existing `jobs_dirty` refresh path: when a session is modified
  from the foreground CLI, set a `sessions_dirty` flag on the daemon's
  shared state and re-read session metadata on next `sessions-list` call.
- Grep for `jobs_dirty` to locate the existing refresh mechanism; replicate
  its pattern for sessions.

### R2 (25.17-R1-remaining) — Persona adapter Bedrock/Vertex plumbing

- `adapter_for` hardcodes "anthropic" for persona requests; Bedrock and
  Vertex personas silently route to the wrong provider or fail.
- Extend `adapter_for` signature to accept a provider hint (from Config
  or session context).
- Update all call sites of `adapter_for` that serve persona paths to pass
  the provider hint.
- Gate: `grep -rn 'adapter_for' src/` — every persona-related call site
  must forward the provider.

### R3 — Non-Rust linting

- Wire `ruff` (Python) and/or `eslint` (JS/TS) into CI, or document the
  ceiling honestly if no non-Rust lintable code exists in-tree.
- If no lintable files exist: add a one-liner to `docs/TECHNICAL.md`
  stating "No Python/JS/TS source in-tree; non-Rust linting not applicable."
- If lintable files exist: add `ruff check` / `eslint` to `scripts/ci-local.sh`
  and the `quality` CI job.

## Success criteria

- R1: `sessions-list` returns current state after a foreground edit
  without daemon restart (manual smoke test).
- R2: persona requests route to the correct provider based on Config;
  no hardcoded "anthropic" in the persona path.
- R3: non-Rust linting either runs in CI or the ceiling is documented.

## Failure criteria

- R1: sessions_dirty flag added but not wired to the refresh path (dead code).
- R2: provider hint accepted but ignored at one or more call sites.
- R3: linting tool added but not wired to CI (same as not adding it).
