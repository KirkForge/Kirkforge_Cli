# Workorder 28.2 — Break the budget↔stratum Circular Dependency

## Status: Planned

## Problem

`src/session/budget.rs` and `src/session/stratum.rs` import each other — a
bidirectional production dependency. gitnexus reports the cycle directly:

```
src/session/budget.rs -> src/session/stratum.rs -> src/session/budget.rs
```

Both directions are **production code** (not test artifacts):

- **budget → stratum:** `budget.rs:349-365` `maybe_escalate_stratum()` is a
  production fn called from `apply_budget_slice` (`budget.rs:245`) and from
  `PreCompactHook` (`budget.rs:745`). It calls
  `crate::session::stratum::current_session_mode()` (`:353`) and
  `set_session_mode(Mode::Full)` (`:355`), gated `#[cfg(feature = "stratum")]`.
- **stratum → budget:** `stratum.rs:6`
  `use crate::session::budget::{BudgetSlicedEvent, BudgetSlicedListener};`, and
  `stratum.rs:133` calls `crate::session::budget::register_sliced_listener(...)`
  to register its `default_budget_sliced_listener` (`stratum.rs:120`).

Root cause: the **session compression mode** (`SESSION_MODE` global + its
accessors) is shared mutable state that *both* subsystems read and mutate, but
it lives inside `stratum.rs`. Budget escalates it on budget pressure; stratum
reads it on slice. The dependency inversion is budget reaching into stratum to
mutate mode — that is the edge to cut.

## Reality-check (verified against code at `5296f41`)

- `stratum.rs:6` imports `BudgetSlicedEvent`, `BudgetSlicedListener` (production,
  top of file). These are pure types defined in `budget.rs:92` / `:103` with **no
  budget state dependency** — just a `pub struct` and an
  `Arc<dyn Fn(BudgetSlicedEvent) -> Option<String>>` typedef.
- `budget.rs:349-365` `maybe_escalate_stratum()` is the only production
  budget→stratum edge. Its body:
  ```rust
  let current = crate::session::stratum::current_session_mode();
  if current == Mode::Lite { crate::session::stratum::set_session_mode(Mode::Full); }
  ```
- The `SESSION_MODE` static + `session_mode()` accessor + `current_session_mode`
  + `set_session_mode` all live in `stratum.rs:93-106`. They hold a
  `kf_compress_core::mode::Mode` — a type from the `kf-compress-core` crate, not
  host-specific.
- Callers of `current_session_mode` / `set_session_mode` beyond budget.rs:
  `stratum.rs` itself, and tests. A re-export from `stratum.rs` keeps external
  callers working.

## Scope

### R1 — Move the session-mode global to `shared/`
- New `src/shared/session_mode.rs`:
  ```rust
  use kf_compress_core::mode::Mode;
  use std::sync::{Mutex, OnceLock};

  static SESSION_MODE: OnceLock<Mutex<Mode>> = OnceLock::new();
  fn session_mode() -> &'static Mutex<Mode> {
      SESSION_MODE.get_or_init(|| Mutex::new(Mode::Full))
  }
  pub fn current_session_mode() -> Mode { /* lock + unwrap_or_else(into_inner) */ }
  pub fn set_session_mode(mode: Mode) { /* lock + unwrap_or_else(into_inner) */ }
  ```
- Delete the originals from `stratum.rs:93-106`; `stratum.rs` adds
  `pub use crate::shared::session_mode::{current_session_mode, set_session_mode};`
  so all existing callers (`executor/mod.rs`, tests, TUI) compile unchanged.
- `budget.rs:349-365` `maybe_escalate_stratum` now calls
  `crate::shared::session_mode::*` — the `use crate::session::stratum` import at
  the test sites (`:1682`, `:1716`) can stay or move; either way the production
  edge is gone.

After R1 the dependency is one-way: `stratum → budget` (listener types +
register) only. **No cycle.**

### R2 — (Optional, smaller win) Move the listener *types* too
- If a future `kf-budget-core` extraction is on the roadmap, also move
  `BudgetSlicedEvent` (`budget.rs:92`) + `BudgetSlicedListener` (`:103`) into
  `shared/` (or `kf-budget-core`). This makes `stratum → budget` a single
  function call (`register_sliced_listener`) rather than a type import. **R2 is
  not required to break the cycle** — ship it only if the type relocation is
  cheap; otherwise leave it and note in `state.md`.

## Success criteria

1. `gitnexus check --cycles` no longer reports the `budget ↔ stratum` cycle.
2. `grep "crate::session::stratum" src/session/budget.rs` returns **0 production

3. The auto-escalation test `test_apply_budget_slice_auto_escalates_lite_to_full_on_approaching`

5. `scripts/test-fast.sh` green; the budget + stratum test suites unchanged.

## Failure criteria (anti-patterns to avoid)

- Moving the mode global but forgetting the `OnceLock` initializer semantics
  (first call wins) — a re-init would reset the mode mid-session.
- Dropping the `unwrap_or_else(|e| e.into_inner())` poison-recovery pattern
  (H1 from the review-fix session; AGENTS.md §7 mandates it).
- Breaking the `#[cfg(feature = "stratum")]` gating so budget escalates even when
  stratum is compiled out (it must remain a no-op then).
- Using a trait/object instead of moving the global — over-engineered for one
  `static` + two accessors (AGENTS.md §5).
