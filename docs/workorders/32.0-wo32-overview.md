## Status: Done (32.1-32.20 shipped; 32.3/32.4/32.15/32.16 pending — see README index)

## Problem

The 2026-08-14 evidence audit (4 parallel read-only subagents grepped every claim
in the 8th-edition production-readiness review) found 11 factual errors in the
review — and, more importantly, surfaced a large inventory of stubbed/deferred
items across WO 27-31 that were either silently deferred (no tracking), tracked
but persistent across multiple series without resolution, or marked "Planned"
in workorder files while claimed "Done" in overview docs.

A second audit pass (2 subagents) read every WO 27-31 workorder file and
extracted every incomplete item. A third pass (1 subagent) verified each item
against source to determine whether it's RESOLVED (shipped) or OPEN (genuinely
needs work). 11 items were RESOLVED; 9 were OPEN. The review's own 8th-edition
short list added 7 more tracked items.

This WO compiles the full inventory and creates individual WO 32 sub-workorders
for each OPEN item, prioritized by persistence (how many series it's survived)
and complexity (L-sized items get their own number for harder tracking).

## Success criteria

Every stubbed/deferred/skipped item from WO 27-31 is either:
1. Verified RESOLVED against source (no action needed), OR
2. Tracked in its own WO file with an honest status line, OR
3. Given a new WO 32 sub-workorder with root cause, approach, gate, and done condition.

No silent deferrals. No "Planned" files claiming "Done" in overview docs without
evidence. No item persistent across 3+ series without a tracking workorder.
