# Workorder 32.6 — Cross-Tool Benchmark: KirkForge vs Codex vs Claude Code

## Status: In progress — framework + runner shipped; live run pending (WO 32.6)

## Problem

WO 30.7 planned the token-budget challenge (128k/64k/32k/16k/8k context windows
on the same task) to validate the "context efficiency" thesis. `crates/kf-bench/`
exists with `BenchReport`, `TaskResult`, `compare_reports` — but it only compares
kf-code runs against prior kf-code runs (self-delta). There is NO Codex/Claude
Code/cross-tool comparison. The review (8th ed §3) calls this "architecturally
supported, not measured."

This is the experiment that validates the product thesis. It's been open since WO
30.7 with no file.

## Root cause

Not a bug — an experiment that hasn't been run. The bench framework exists but
the cross-tool harness + runner scripts don't.

## Approach

1. Define 3-5 representative tasks (bug fix, feature add, refactor, docs).
2. Run each task at 5 context budgets (128k/64k/32k/16k/8k) on:
   - KirkForge (kf-code)
   - Claude Code (if available)
   - Codex CLI (if available)
3. Measure: tokens consumed, turns taken, success/failure, wall-clock time.
4. Compare via `compare_reports` (extend to accept external-tool reports).
5. Publish results in `docs/benchmarks/cross-tool-2026-08.md`.

## Files to touch

- `crates/kf-bench/` — extend to accept external-tool reports
- `docs/benchmarks/cross-tool-2026-08.md` — results
- `scripts/run-cross-tool-bench.sh` — runner script

## Gate

- `cargo test -p kf-bench`
- Results published with raw data

## Done condition

The benchmark is run, results published, and the "context efficiency" thesis is
either validated or refuted with data.
