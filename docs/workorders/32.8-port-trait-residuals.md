# Workorder 32.8 — WO 28.1 Port-Trait Residuals (3 Imports)

## Status: Pending

## Problem

WO 28.1 cut the `tools ↔ session` cycle (imports 26→3 per ADR-073). The 3
remaining imports are disclosed as "non-cyclic port-trait residuals" — they're
not cyclic, but they prevent full crate-extraction of `tools/`. All 3 still
exist (verified 2026-08-14):
- `src/tools/bash.rs:2` — `use crate::session::bash_runner::{...}`
- `src/tools/bash.rs:1` — `use crate::session::bash_jobs::global_registry`
- `src/tools/remember.rs:7` — `use crate::session::memory::{...}`

## Approach

For each residual, extract a port trait in `shared/` that `tools/` can use
without importing `session/`:
1. `bash_runner` shell-I/O → `shared/bash_io` trait
2. `bash_jobs` registry → `shared/job_registry` trait
3. `remember::memory` → already tracked in WO 29.6 (memory-palace port)

## Files to touch

- `src/shared/` — new port traits
- `src/tools/bash.rs` — replace `session::` imports with `shared::`
- `src/tools/remember.rs` — replace `session::memory` with `shared::` or `crates/kf-memory-store`

## Gate

- `cargo check --workspace --all-targets`
- `cargo clippy --all-targets -- -D warnings`
- `grep 'use crate::session' src/tools/` → 0 production imports

## Done condition

Zero `use crate::session::` imports in `src/tools/` production code. `tools/` is
cratextractable.
