# WO 33.1 — Concurrency Cancellation + Trigger Dedup

## Status: Pending

## Problem
No `concurrency` block in ci.yml. 3 quick pushes = 3 full CI runs burning
minutes. Push + PR triggers can test the same commit twice.

## Approach
Add to `.github/workflows/ci.yml`:
```yaml
concurrency:
  group: ci-${{ github.workflow }}-${{ github.event.pull_request.number || github.ref }}
  cancel-in-progress: true
```
Audit triggers so push+PR don't duplicate.

## Files
- `.github/workflows/ci.yml`

## Gate
- YAML valid
- New pushes cancel old runs

## Done
Concurrency block present. Old runs cancel on new push.
