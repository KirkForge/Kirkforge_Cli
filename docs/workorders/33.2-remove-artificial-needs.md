# WO 33.2 — Remove Artificial needs: Dependencies

## Status: Pending

## Problem
`e2e` and `coverage` jobs have `needs: quality` but they don't logically
depend on quality passing — they depend on the source checkout. This
creates an artificial sequential bottleneck.

## Approach
1. Remove `needs: quality` from `e2e` and `coverage` jobs.
2. Have them depend only on `static` (fmt/repo-checks) if anything.
3. Run in parallel with quality.

## Files
- `.github/workflows/ci.yml`

## Gate
- YAML valid
- Jobs run in parallel

## Done
e2e + coverage start immediately, not after quality.
