# WO 33.5 — Nextest Profiles

## Status: Pending

## Problem
Test timeout/filter config is inlined in CI YAML. No profile system.
No way to say "run only fast tests" vs "run everything".

## Approach
Create `.config/nextest.toml` with profiles:
- `default` — standard
- `ci-fast` — lib tests only, 60s timeout, fail-fast
- `ci-full` — all tests, 120s timeout, no-fail-fast
- `integration` — integration tests, 300s timeout
- `e2e` — e2e-tests feature, 600s timeout

Then CI says `cargo nextest run --profile ci-fast` instead of
inline config flags.

## Files
- `.config/nextest.toml` (new)
- `.github/workflows/ci*.yml` — reference profiles

## Gate
- `cargo nextest run --profile ci-fast -p kf-code --lib` works
- `cargo nextest list --profile ci-fast` shows filtered set

## Done
Profiles defined, CI uses them, inline config removed.
