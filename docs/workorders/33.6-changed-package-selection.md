# WO 33.6 — Path-aware / changed-package test selection

## Status: Done

## Problem

PR CI ran `cargo nextest run --workspace`, recompiling and retesting the
entire 14-package workspace on every PR — including docs-only changes and
single-crate changes that touch one package out of thirteen. PR feedback
time was dominated by unaffected packages.

## Approach

1. **`scripts/changed-packages.sh <base-ref>`** — maps `git diff --name-only
   <base>..HEAD` to affected cargo packages, including the reverse-dependency
   closure. Outputs a space-separated package list on stdout (empty or
   `__NO_RUST_CHANGES__` when there is nothing Rust-relevant to test).

2. **Path filters:**
   - Rust-relevant: `*.rs`, `Cargo.toml`, `Cargo.lock`, `build.rs`,
     `benches/**`, `tests/**`, `crates/*/Cargo.toml`.
   - Docs-only: `docs/**`, `*.md`, `**/docs/*.md`. A purely docs change
     emits `__NO_RUST_CHANGES__` → clippy + fast-tests skip entirely.
   - No Rust files (e.g. scripts-only): same `__NO_RUST_CHANGES__` marker.

3. **Reverse-dependency closure** — hardcoded adjacency table
   (`ponytail:` ceiling documented in the script). The workspace has 13
   crates and 4 inter-crate edges; the root `kf-code` crate depends on
   every workspace member, so any crate change pulls in `kf-code`
   automatically. The table lists only the *additional* inter-crate edges:
   `kf-routing` ← `kf-memory-store`, `kf-orchestrator`; `kf-memory-store`
   ← `kf-orchestrator`; `kf-plugin-sdk` ← `kf-plugin-host`.

4. **`ci-pr.yml` wiring** — a new `changes` job (needs `fmt`) runs the
   script with `fetch-depth: 0` and exposes the package list as a job
   output. `clippy` and `fast-tests` now `needs: changes` and gate
   themselves with `if:` on the output. `fast-tests` builds
   `cargo nextest run --profile ci-fast --lib --locked -p <a> -p <b> ...`
   from the list. `clippy` still runs on the full workspace (it is the
   compile gate; a crate change can break a caller that the package filter
   would not compile). `fmt` always runs (cheap, no rust compile).

## Files

- `scripts/changed-packages.sh` (new)
- `.github/workflows/ci-pr.yml` (edited: `changes` job + `if:` gates)

## Gate

- `bash scripts/changed-packages.sh origin/dev` prints the affected list.
- `python3 -c "import yaml; yaml.safe_load(open('.github/workflows/ci-pr.yml'))"`
  (YAML valid).
- Classifier unit assertions (26 cases) pass — see workplan.md.

## Done

- `ci-pr.yml` consumes the script output and skips rust jobs on docs-only.
- Reverse-dep closure verified: `kf-routing` change →
