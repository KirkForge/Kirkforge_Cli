# WO 34.6 — Jobs tab → structured job monitor

## Status: Pending

## Problem

`src/tui/widgets/tabs.rs:240` renders Jobs by dumping
`state.session.cached_jobs_output` (the text output of `/jobs`) line by
line. It's rendering cached text, not a structured UI.

## Approach

1. Parse the jobs data into a structured list with columns:
   - Status icon: ● running, ✓ done, ✗ failed
   - ID
   - Command (truncated)
   - Elapsed time
   - Status text
2. Interactive: ↑↓ selects, `Enter` shows details (command, started,
   output), `C` cancels, `L` shows logs, `Esc` closes.
3. If the cached output is the only data source, parse it into rows. If
   the jobs data is available as a struct, use that directly.
4. Details view: shows full command, start time, status, and output
   preview.
