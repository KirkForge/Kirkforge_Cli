# WO 34.8 — Welcome screen: quick actions + recent sessions

## Status: Pending

## Problem

`src/tui/widgets/welcome.rs:71-73` shows a single line:
`"Type a message or /help for commands. Ctrl+O to open a project."`
The welcome screen is functional but not welcoming. It doesn't teach the
product, show recent sessions, or surface quick actions.

## Approach

1. Restructure the welcome screen:
   - **Banner**: `k i r k f o r g e` (keep existing)
   - **Subtitle**: `AI coding assistant for your repository`
   - **CWD**: current working directory (keep existing)
   - **Recent sessions**: show 3-5 recent sessions with timestamps + message
     counts (if available from session index)
   - **Quick actions**:
     - `/ Commands`
     - `@ Add a file`
     - `Ctrl+K Command palette`
     - `Ctrl+S Sessions`
   - **Status**: `● Ready · <model name>` at the bottom
2. Any keystroke dismisses the welcome (keep existing behavior).
3. Recent sessions come from the session index if available; if not, skip
   that section (don't show empty headers).

## Files to touch

- `src/tui/widgets/welcome.rs` — rewrite `render_welcome`
- Tests for the new layout

## Gate

- `cargo clippy -p kf-code --lib --tests -- -D warnings`

## Done condition

Welcome screen shows quick actions, recent sessions (if available), and
the current model. First-time users learn the product without /help.
