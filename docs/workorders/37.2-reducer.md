# WO 37.2 — The reducer: make DelegationResult.packet real

## Status: Done

## Problem

`DelegationResult.packet` is always `None` (`delegate.rs:269`) — the
crate's own docs (lib.rs:15, correction.rs:6, types.rs:3) call the
reducer "NOT ported". The correction loop therefore decides without a
reduced view of verification state. This is kf-orchestrator's last
unwired concept.

## Root cause

The original was TS (`reducer.ts`) and NO TS source exists in this
repo (verified 2026-08-20) — there is nothing to port. What exists:
`kf_routing::correction` carries the full state vocabulary
(`Changes`, `GraphState`, `LintState`, `TypesState`,
`SecurityState`, `Verification`, `OverallVerdict`, `VerifierPolicy`)
and `kf-orchestrator/src/verifier.rs` produces `SecurityFinding`s.
The missing piece is the FOLD: many verification results → one
`ReducedStatePacket`.

## Approach (design-from-contract; write the ADR first)

1. **ADR-076**: pin the reducer contract — inputs (verifier findings
   per category + the delegation's changes), the fold rules (how
   `OverallVerdict` derives from per-category states; what makes a
   packet `Pass` vs `NeedsCorrection` vs `Fail`), where it runs in
   `delegate()` (after mode execution, before correction decide), and
   what the correction loop consumes from it. Two status spots + index
   + ADR count in TECHNICAL.md (state.md folded at merge).
2. Implement `reducer.rs` in kf-orchestrator: pure functions,
   `ReducedStatePacket` populated from the state types + verifier
   findings. Update `types.rs` if the packet shape needs fields beyond
   what's declared (it's currently an empty/placeholder struct — check
   and give it the real shape the ADR pins).
3. Wire: `delegate()` builds the packet after mode execution; the
   correction loop's decide step (`kf_routing::correction::
   decide_correction`) receives it. Keep the API additive — existing
   71 tests must stay green untouched.
4. Tests: fold rules table-driven (each category → verdict mapping,
   mixed categories, empty findings → Pass); a delegate integration
   test asserting a non-None packet reaches the result (extend the WO
   36.5 e2e pattern); correction-decide consumes the packet (unit).
