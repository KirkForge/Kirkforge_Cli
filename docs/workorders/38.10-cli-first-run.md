# WO 38.10 — CLI first-run + scriptability

## Status: Pending

## Problem (CLI audit — verified by live runs)

1. **P0 — first-run banner pollutes machine-readable stdout**
   (config/mod.rs:235 println!): `--output stream-json` first run on a
   fresh machine emits a non-JSON line → breaks every scripted
   consumer on exactly the run that matters most.
2. **P0 — no model configured → cryptic 400, wrong exit class**
   (run_session.rs:66 → adapters/mod.rs:272-274): empty model →
   OpenAI-compat fallback against Ollama → raw 400, exit 1, no hint;
   the banner carrying the fix is erased by the alt screen in TUI.
3. **P1 — no one-shot prompt flag**: every competitor has
   `claude -p` / `codex exec` / `opencode run`; kf-code needs
   `echo | run --non-interactive`.
4. **P1 — blank line in piped stdin silently truncates the session**
   (line_mode.rs:135-141); multi-paragraph prompts lose everything
   after the first empty line.
5. **P1 — NO_COLOR kills the TUI entirely** (run_session.rs:109-110,
   spec violation); `--non-interactive` on a TTY shows no prompt
   (looks hung); seven core `run` flags have empty help text;
   bad config.toml → warn + defaults instead of exit 5; `bench run`
   exits 0 on 0% success; `--output json` on hard error emits NO json
   (error propagates before summary); metrics/verify ignore
   KF_CODE_DATA_DIR (reads another installation's data on
   macOS/Windows); JSON summary session.id is a literal string and
   started_at is actually end time.
6. **P2 set**: replay prefix-miss error, no progress on update/bench,
   Ctrl-C exits 0 not 130, hard-coded hint path, `-o` short-flag
   drift, no `config show`/`models`/jobs CLI, uninstall.sh dir
   mislabel, undocumented env knobs.

## Approach

1. Banner → stderr (1 line).
2. Empty-model guard at session start: print the guidance + exit 3
   (ModelUnreachable class) instead of the 400.
3. `run -p "<prompt>"` (or positional) one-shot: append to input
   queue before entering the loop; also fixes the multi-paragraph
   pipe problem for the arg form; piped-stdin blank-line handling
   documented + `--read-stdin-full` escape hatch.
4. NO_COLOR decoupled from the TUI decision (only TERM=dumb /
   non-tty degrade); non-interactive-on-TTY prints one "reading from
   stdin" line; doc comments on the seven bare flags (incl. the
   denies-all note on --non-interactive); hard config-parse failure →
   exit 5 (soft-merge unknown-key warnings stay warnings); bench
   exit-code reflects success (flag-gate if needed); json output
   emits an error object before exit 1; metrics/verify honor
   KF_CODE_DATA_DIR; summary carries the real session id + start
   time.
5. P2s as a polish commit.

## Gate

Standard + tests: first-run JSON purity (fresh data dir, assert every
stdout line parses); empty-model → exit 3 + hint; `-p` round-trip;
NO_COLOR keeps TUI selection logic (unit); bench failure exit.

## Done condition

A first-time scripter's first three commands (install, run -p, pipe)
work byte-clean; every failure mode names its fix and exits by class.
