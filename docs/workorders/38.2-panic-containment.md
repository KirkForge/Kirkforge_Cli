# WO 38.1 — Panic containment + terminal survival

## Status: Done

## Problem (audit: panic-surface + TUI audits)

1. **P0 — `panic = "abort"` (Cargo.toml:335) neuters all
   catch_unwind containment** (dispatch.rs:658, verifier bus, plugin
   host, compress-core) in release builds, AND `TerminalGuard` Drop
   never runs on abort → user's terminal left in raw/alt-screen. No
   `std::panic::set_hook` exists anywhere (verified).
2. **P0 — session picker clamp panic** at terminal heights 8-11
   (`src/tui/components/session_picker.rs:136`:
   `(h*3/4).clamp(12, h)` with `MIN_HEIGHT = 8`) — the exact
   approval-dialog bug class; reachable at startup and `/resume`.
3. **P1 — poison-intolerant locks deviating from the repo's own
   `into_inner` convention**: `notebook_edit.rs:181` (undo mutex —
   siblings write_file/edit_file/undo.rs all tolerate poison; this
   one unwraps), `computer_use.rs:262,269,287` (session lock held
   across headless-chrome calls), `kf-lsp/src/lib.rs` shutdown paths
   ×6, `event_bus.rs` 12× `.expect("event bus mutex poisoned")`.
4. **P2 — `short_ts` byte-slices possibly-non-ASCII timestamps**
   (`session_picker.rs:249-255`) → mid-char slice panic.

## Approach

1. Panic hook installed before `enable_raw_mode()` in TUI startup
   (and the standalone session picker): runs `force_terminal_reset` +
   prints the panic message after reset. Hooks run even under
   `panic=abort` — keep abort, keep the size win. Test: install hook,
   panic in a test thread with raw-mode-ish state asserted restored
   (or assert hook composition behavior unit-level).
2. Session picker: `MIN_HEIGHT = 12` + safe clamp ordering (mirror
   `approval_dialog_area`). Test at heights 8..=11 (the panicking
   range) + fuzz like approval's.
3. Lock conversions to `unwrap_or_else(|e| e.into_inner())` /
   `match` pattern per the sibling files' precedent — one commit
   sweep, each site gets the pattern its sibling uses.
4. `short_ts`: parse via chrono or char-boundary-safe slicing.

## Gate

clippy/fmt/nextest standard; new tests: picker heights 8-11 + fuzz;
panic-hook test; TUI suite green.

## Done condition

Any panic in the shipped binary leaves a clean terminal; no
poison-intolerant lock remains on a turn-critical path; the picker
can't panic on small terminals.
