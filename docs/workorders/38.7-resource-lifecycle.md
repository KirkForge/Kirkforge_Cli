# WO 38.7 — Resource lifecycle + worktree sweep

## Status: Pending

## Problem (lifecycle audit)

1. **P0 — worktree accumulation (CONFIRMED LIVE: 29 stale
   kf-code-session-* dirs in /tmp on this machine)**: Drop fails when
   the parent repo moved/git unavailable → both the checkout and the
   `.git/worktrees` registration leak; no boot sweep; crashed
   sessions leak per-crash.
2. **P1 — conversation torn-append merge** (see 38.6, same audit).
3. **P1 — plugin verifier child unbounded + bus-lock hold**
   (verifier/bus.rs:276, plugin-host verifier.rs:65) — hang wedges
   every subsequent turn (hooks got 5s; verifiers got nothing).
4. **P1 — correction formatter child: no timeout, no kill_on_drop,
   stdin inherited** (correction.rs:267-296).
5. **P2 set**: .tmp leftovers on write failure, MCP stdin-take orphan,
   stale-recovery bail on non-worktree dir, jobd pid-before-bind,
   panic-skip claimed_sessions, test-helper leaks.

## Approach

1. Drop fallback: on git failure, `fs::remove_dir_all(worktree_path)`
   + `git worktree prune` best-effort; boot sweep of
   `$TMPDIR/kf-code-session-*` older than N days (age-guarded like
   the undo orphan sweep).
2. Verifier/formatter: mirror the hook pattern — timeout + process-
   group kill + Stdio::null (overlaps 38.3 P1-4/P1-5; coordinate in
   one branch if both are in flight).
3. P2s as a single hygiene commit, each with its one-line test where
   cheap.

## Gate

Standard + tests: Drop-fallback leaves no dir when git fails; sweep
removes age-qualified dirs only; formatter kill-on-timeout; the 29
live dirs are reaped by the sweep on this machine (manual verify,
paste output).

## Done condition

Worktrees cannot outlive their session by more than the sweep window;
no unbounded child in the verifier path.
