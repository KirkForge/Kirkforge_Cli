## Status: Pending

them. `run_session.rs:558-580` builds `SessionStores` and drops it.

escalation listener, no budget hooks — `apply_budget_slice`

dead code). Wiring stores without fixing the registry makes

compress later sessions into session #1's store.

   listener registration with the FIXED registry).
3. Budget `init_from_config` runs on attach (it exists, currently
   dead); stratum escalation listener registers.

   present-tense-fact; changelog.
5. Tests: integration test asserting slicing fires in a REAL run
   session path (not manually-wired like 35.5's); multi-executor
   isolation test (two executors, slices land in their own stores).
