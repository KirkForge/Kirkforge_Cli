# WO 39.2 — Claude compat phase 1: skills, commands, MCP discovery

## Status: Pending

## Problem

kf-code already parses `.claude/skills/*/SKILL.md` (skills.rs:485-546
— frontmatter parser handles the stock format) and scans
`.claude/skills` BY DEFAULT (:126), but a Claude skill without a
`trigger` field registers unreachable (dispatch is get_by_trigger
only). `.claude/commands/*.md` and `.mcp.json` have no loaders. The
ecosystem's markdown layer is one glue pass away — and OpenCode's
compat reputation rests on exactly this glue.

## Approach (from the compat exploration, ~250 LOC total)

1. **Skill trigger derivation (~10 LOC)**: `parse_frontmatter` —
   when `trigger` is empty and `name` non-empty →
   `trigger = format!("/{name}")`. Every existing Claude skill
   (including this repo's own 6 GitNexus skills) becomes an
   invocable slash command. Test with the real gitnexus-cli SKILL.md
   fixture.
2. **Commands loader (~80-150 LOC)**: scan `.claude/commands/**/*.md`
   (+ optional `~/.claude/commands`) → register as skills; filename-
   stem → trigger; rewrite `$ARGUMENTS`/`$1..$9` → `{{args}}`
   positional substitution. Reuse the frontmatter walker.
3. **`.mcp.json` discovery (~100 LOC + security gate)**: if
   `./.mcp.json` exists, parse `mcpServers` → `Vec<McpServerConfig>`
   (command/args/env → env_vars, url → transport=http, auth →
   bearer_token), merge in run_session before McpClientManager::new.
   GATE: `tools.load_project_mcp_json` config flag (default on) +
   first-load-per-project approval prompt — a cloned repo's
   .mcp.json is attacker-controllable spawn config (the security
   audit's "becomes P1 the day workspace MCP config lands" note —
   the gate IS this WO's answer).
4. Docs: TECHNICAL.md compat section; CHANGELOG.

## Gate

Standard + tests: real-format SKILL.md fixture gets a trigger;
command file with $ARGUMENTS renders; .mcp.json with one stdio + one
http server registers both (wiremock for http); approval gate blocks
first load and admits on approval (persisted per project).

## Done condition

Drop a Claude plugin's skills/commands/.mcp.json into a project and
kf-code picks them up on next start, with the MCP gate asking once.
