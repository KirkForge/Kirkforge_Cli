# WO 41.7 — Property/fuzz testing of the glob matcher

## Status: Pending

## Problem

`glob_match()` is hand-rolled recursive backtracking with `*`, `**`, `?`, UTF-8, `/`. Security-sensitive code with no fuzz/property testing.

## Approach

Add a `proptest` suite (proptest is likely a dev-dep or can be added) covering: `glob_match` with edge cases (`**`, `***`, `a/**/b`, `foo**bar`, `*/*`, Unicode, empty, very long); `deny_command_matches` and `allow_command_matches` with compound commands; `split_compound_clauses` with separators; `normalize_command_pattern`. Property: for any pattern, `glob_match(pattern, text)` is deterministic and total (never panics). For valid glob patterns, `**` crosses `/` and `*` doesn't.

## Gate

Standard clippy (Linux + Windows cross-compile), fmt, nextest. proptest runs pass.
