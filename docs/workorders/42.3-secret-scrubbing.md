# WO 42.3 — Secret scrubbing: expand coverage

## Status: Pending (P0 — credential exfiltration primitive)

## Problem (verified: security agent)

`is_secret_env_name` (`src/session/bash_runner/mod.rs:495`) matches `*_API_KEY`, `*_TOKEN`,
`*_SECRET` and exact `API_KEY`, `TOKEN`, `SECRET`. Misses:
- `AWS_SECRET_ACCESS_KEY` (ends with `_ACCESS_KEY`, not `_API_KEY`)
- `AWS_ACCESS_KEY_ID` (ends with `_ID`)
- `*_PASSWORD` (only `_SECRET` matches)
- `*_PRIVATE_KEY`
- `*_CREDENTIAL`
- `*_PASS`
- `*_CONN_STRING` / `*_CONNECTION_STRING`

The canonical AWS credential env var leaks to model bash.

## Approach

Expand `is_secret_env_name` suffix list: add `_ACCESS_KEY`, `_PASSWORD`, `_PRIVATE_KEY`,
`_CREDENTIAL`, `_PASS`, `_CONN_STRING`, `_CONNECTION_STRING`. Add exact matches:
`AWS_SECRET_ACCESS_KEY`, `AWS_ACCESS_KEY_ID`, `GITHUB_TOKEN` (already caught by `_TOKEN`).
Update tests.

## Gate

Standard. Test: `AWS_SECRET_ACCESS_KEY` scrubbed, `DB_PASSWORD` scrubbed, `MY_PRIVATE_KEY`
scrubbed.
