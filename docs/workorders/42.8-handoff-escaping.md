# WO 42.8 — Handoff delimiter escaping (WO 41.2 still open)

## Status: Pending (P0 — prompt injection vector)

## Problem (verified: orchestration agent)

`fence_handoff` (`src/session/parallel_orchestrator.rs:331-339`) truncates at 8KB and
wraps with `<<<BEGIN/END UNTRUSTED HANDOFF>>>` but does NOT escape those delimiters
inside the body. A malicious handoff containing `<<<END UNTRUSTED HANDOFF>>>` breaks
the fence. No test covers it. The patch-marker spoof IS mitigated (`rsplit_once` +
test) but the delimiter spoof is open.

## Approach

Escape any literal `<<<BEGIN UNTRUSTED HANDOFF>>>` or `<<<END UNTRUSTED HANDOFF>>>`
in the handoff body by replacing angle brackets with neutralized form
(`[[BEGIN UNTRUSTED HANDOFF]]`). Real delimiters added after escaping are unaffected.
Test: handoff containing the end-delimiter string cannot break the fence.

## Gate

Standard. Test: `handoff_delimiter_spoof_is_escaped`.
