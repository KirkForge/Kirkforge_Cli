## Round 3 extension — fresh segment audit (43.18-43.24)

Seven more agents audited segments nobody had covered. These are NEW
findings (not backlog verification). Headlines:

- **43.18**: line mode has no SIGINT handler (Ctrl-C orphans bash children,
  skips carryover); audit BufWriter only flushes on Drop which
  `panic="abort"` never runs; grep tool blocks the runtime (missed by the
  WO 38.3 sweep). Concurrency segment otherwise clean — documented.
- **43.19**: TUI unicode-slice panics already fixed (WO 38.2/38.11); real
  bug is `set_cursor_line_col` mixing byte offset + char count → wrong
  cursor on multibyte input, ships green because tests are ASCII-only.
  5 render modules have zero tests (commands/jobs.rs 911:0 worst).
- **43.20**: headless_chrome ungated behind empty `computer_use` feature
  (~1-2 MB); arboard default features drag image/png/flate2 (~0.5-1 MB);
  http 0.2 duplicate via aws-sigv4 1.2→1.3 bump.
- **43.21**: audit sink never fsyncs (≤8KB lost on crash — same root as
  43.18 item 2); torn final line poisons `verify_chain` forever; one bad
  UTF-8 byte discards the whole session log; CachedIndex has no version
  stamp. Session NDJSON itself is solid (per-append fsync + heal).
- **43.22**: Bedrock injects `[DONE]` on mid-stream drops → bypasses
  truncation path; Retry-After never honored; lockstep retry jitter;
  `usage:None` reads as zero-cost. Retry/idle-timeout/SSE framing otherwise
  solid.
- **43.23**: no PDEATHSIG — parent abort orphans ALL subprocesses (children
  in own pgroups); MCP 10s reader idle-kill vs 30s request timeout
  mismatch; kf-plugin-host tool/hook exec has no timeout/killpg (latent,
  unwired). Hooks + bash jobs + plugin wrapper lifecycle solid.
- **43.24**: ~25 truly assertion-free tests (worst:
  `build_reqwest_client_returns_a_client` asserts nothing); 1 stale
  `#[ignore]` (kf-rbac jwt cites Done WO 32.10); security deny/allow test
  ratios healthy; WO 40.4 no-sleeps held.

## Round 4 extension — full-coverage segment sweep (43.25-43.39)

Round 3 covered concurrency, TUI, deps, persistence, adapters, subprocesses,
and test assertions. Round 4 dispatched seven fresh read-only agents over the
segments nobody had swept (executor/turn, tools, session/mcp/prompt/verifier,
TUI widgets/commands, sandbox/security, daemon/jobs/cli, and the `crates/*`).
These are NEW findings — no re-scoping of existing 43.x bugs. Headlines:

- **43.25**: three raw `&str[..byte_idx]` UTF-8 panic sites (doom-loop error
  truncate, stream preamble cap, TUI PTY 64KiB tail cut — the last misread by
  43.19 as "boundary-safe"). Two are on the executor task outside the tool
  catch_unwind → session abort.
- **43.26**: workflow bash steps + plugin-bus verifier spawn subprocesses with
  no timeout/cancel/kill_on_drop — hung child blocks forever.
- **43.27**: atomic-write clobbers target permissions (exec stripped, 0600
  secret widened); notebook_edit pushes undo before write → phantom undo on
  failed write.
- **43.28**: background/scheduled/PTY bash paths skip the foreground secret
  scrub → model reads provider/API secrets via bash_status/printenv.
- **43.29**: prompt compaction OOB panic — minify_old_messages indexes the
  shorter microcompacted vec with longer original indices on the over-budget
  path.
- **43.30**: pre-tool hook `deny` is ineffective for file tools (veto fires
  after the write in `record_tool_result`).
- **43.31**: doom-loop banner hardcodes selection 0 — highlights Break but
  Enter runs the hidden user-selected action.
- **43.32**: `KF_CODE_*` env overrides never applied in production — the whole
  layer is test-only (`#[cfg(test)]`).
- **43.33**: jobd `--stop` sends no auth token, ignores response, has no
  timeout, and deletes the pid file even when the daemon refused to stop.
- **43.34**: context-index `retrieve()` still smears unresolved edges (the
  multi-MB prompt bug the sibling `to_retrieval_result` fix missed).
- **43.35**: kf-memory-store stale `.lock` latches the store forever after a
  crash (no PID-liveness/age check).
- **43.36**: kf-compress-core Lite mode is a no-op (gate `||` makes it
  identical to Off).
- **43.37**: verifier `pending_corrections` is write-only dead state (latent
  double-apply); MCP pending-map entry leaks on channel-close-without-reader.
- **43.38**: glob walks the disk synchronously, computer_use does
  `std::thread::sleep` on the async runtime, and shell-glob redirection
  targets bypass the dangerous-path gate.
- **43.39**: kf-bench markdown-delta recomputes baseline from the union task
  set → rendered rates contradict the regression signal.
