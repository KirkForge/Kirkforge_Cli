## Round 3 extension — fresh segment audit (43.18-43.24)

Seven more agents audited segments nobody had covered. These are NEW
findings (not backlog verification). Headlines:

- **43.18**: line mode has no SIGINT handler (Ctrl-C orphans bash children,
  skips carryover); audit BufWriter only flushes on Drop which
  `panic="abort"` never runs; grep tool blocks the runtime (missed by the
  WO 38.3 sweep). Concurrency segment otherwise clean — documented.
- **43.19**: TUI unicode-slice panics already fixed (WO 38.2/38.11); real
  bug is `set_cursor_line_col` mixing byte offset + char count → wrong
  cursor on multibyte input, ships green because tests are ASCII-only.
  5 render modules have zero tests (commands/jobs.rs 911:0 worst).
- **43.20**: headless_chrome ungated behind empty `computer_use` feature
  (~1-2 MB); arboard default features drag image/png/flate2 (~0.5-1 MB);
  http 0.2 duplicate via aws-sigv4 1.2→1.3 bump.
- **43.21**: audit sink never fsyncs (≤8KB lost on crash — same root as
  43.18 item 2); torn final line poisons `verify_chain` forever; one bad
  UTF-8 byte discards the whole session log; CachedIndex has no version
  stamp. Session NDJSON itself is solid (per-append fsync + heal).
- **43.22**: Bedrock injects `[DONE]` on mid-stream drops → bypasses
  truncation path; Retry-After never honored; lockstep retry jitter;
  `usage:None` reads as zero-cost. Retry/idle-timeout/SSE framing otherwise
  solid.
- **43.23**: no PDEATHSIG — parent abort orphans ALL subprocesses (children
  in own pgroups); MCP 10s reader idle-kill vs 30s request timeout
  mismatch; kf-plugin-host tool/hook exec has no timeout/killpg (latent,
  unwired). Hooks + bash jobs + plugin wrapper lifecycle solid.
- **43.24**: ~25 truly assertion-free tests (worst:
  `build_reqwest_client_returns_a_client` asserts nothing); 1 stale
  `#[ignore]` (kf-rbac jwt cites Done WO 32.10); security deny/allow test
  ratios healthy; WO 40.4 no-sleeps held.
