## Problem

Verified via `cargo tree --workspace` (434 crates in kf-code's release graph; no
target/release/kf-code exists — current size unknown, measure first):

- arboard (Cargo.toml:199) default `image-data` links image v0.25.10 → png →
  flate2 into kf-code solely via arboard (its only consumer); sole use is
  `set_text` (src/tui/clipboard.rs:32-34).
- headless_chrome (:215) is NOT optional; `computer_use` feature (:289) is an
  empty feature — zero `cfg(feature = "computer_use")` in src/. Real impls
  (chrome_launcher.rs:96-187, computer_use.rs:947-1162) always compile, dragging
  tungstenite + rand 0.9/0.10 + getrandom ×3. PlaceholderTab fallback already
  exists (tools/mod.rs:286, run_session.rs:394-398). Precedent: portable-pty and
  seccompiler are already optional (:241, :247).
- http v0.2.12 + http-body v0.4.6 duplicate http v1.x solely via aws-sigv4
  1.2.0 → aws-smithy-http 0.60.12. aws-sigv4 1.3.8 requires http ^1.3.1
  (crates.io index verified).
- base64 0.22 (root :193, kf-orchestrator) vs 0.23 (tiktoken) — two copies.
- unicode-width 0.1.14 (rustyline 14) vs 0.2.2 — two copies.
- handlebars (:147) pulls pest/pest_derive/pest_generator/pest_meta for exactly
  2 call sites (prompt/mod.rs:216, :386) rendering one template
  (prompts/system.hbs: 1× `{{#each}}`, 2× `{{#if}}`, 10 tags total).
- chrono-tz (:181) embeds full IANA db for 1 use site (jobs/schedule.rs:280).
- Clean, no action: single TLS stack (reqwest rustls, :130; no native-tls);
  no unused direct deps (similar/globset/textwrap/cron/subtle/rustyline/
  tree-sitter-js+bash all have use sites; indexmap/dashmap/parking_lot/
  crossbeam are transitive-only); rand 0.8 + itertools 0.10 dev-only;
  syn 2/3, darling ×2, convert_case ×2, winnow ×2 are proc-macro-only
  (build-time cost, zero size). rusqlite bundled (~1.5 MB) accepted by design
  (:97-101). tokio "full" trim REJECTED: signal + net used first-party and
  reqwest re-enables the rest. Profile :335-340 (z/lto/cgu-1/strip/abort)
  verified; members inherit — Cargo forbids member overrides anyway.

## Root cause

Deps added per-WO with default features and no size gate at add time;
`computer_use` is documented default-OFF (:288) but its heavy impl was never
actually compile-gated.

## Approach

1. `aws-sigv4` "1.2" → "1.3" (:217) — drops http 0.2 + http-body 0.4. ~100-200 KB.
2. `arboard = { version = "3", default-features = false }` (:199) — drops
   image+png+flate2. ~0.5-1 MB. Verify Wayland copy path still works.
3. base64 → "0.23" (root :193 + crates/kf-orchestrator/Cargo.toml) — unifies
   with tiktoken. ~10-20 KB.
4. rustyline 14 → 15/16 (:150) — dedupes unicode-width. Small; check API.
5. Replace handlebars with ~30-line `{{var}}`/`{{#each}}`/`{{#if}}` renderer +
   a construct-freeze test on system.hbs — drops pest stack. ~300-500 KB.
   Skip if templates outgrow the subset.
6. headless_chrome `optional = true` + `computer_use = ["dep:headless_chrome"]`,
   cfg-gate chrome_launcher.rs + real impls (PlaceholderTab stays ungated).
   ~1-2 MB, biggest win. DEFER-disclosure required: default builds lose local
   Chrome execution until the feature is on; align messaging with 43.5.
