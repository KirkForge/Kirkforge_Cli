# WO 43.38 — Async blocking in tools (glob walk, computer_use sleep) + shell-glob redirection bypass

## Status: Planned

## Problem

Fresh segment audit (round 4). Two more async-runtime-blocking sites (the
class 43.18 swept from grep but these escaped), plus one sandbox-gate bypass.

1. **glob walks synchronously on the async runtime**
   (`src/tools/glob.rs:84`): `glob.run` is async but iterates
   `ignore::WalkBuilder` with a blocking `std::fs` traversal — no
   `spawn_blocking` (unlike the grep fix pattern in 43.18). The model supplies
   `base_dir` with no size/top-level check, so `base_dir="/"` walks the whole
   disk and stalls the tokio worker. Per-file `check_traversal` filters output
   but the walk cost / runtime stall is unbounded.

2. **computer_use `wait` does `std::thread::sleep` on the async runtime**
   (`src/tools/computer_use.rs:430`): `run_hosted_action`'s `wait` branch
   calls `std::thread::sleep(Duration::from_secs_f64(secs.max(0.0)))` with a
   model-supplied, unbounded duration, parking the tokio worker. Should be
   `tokio::time::sleep`.

3. **Shell glob bypass of dangerous-redirection gate** (`src/shared/bash_safety.rs:220`):
   `redirects_to_dangerous_path`/`tee_to_dangerous_path` (`:247-264`) match the
   literal redirection target token against fixed prefixes (`/etc/`, etc.);
   `normalize_for_safety` (`:106-147`) keeps a bracket intact. A
   shell-glob/character-class target such as `> /e[t]c/hosts` or `> /etc/host*`
   does not start with the literal prefix, so the gate misses it while `/bin/sh`
   expands it to the real path at execution. Exploitable only when landlock is
   off/unsandboxed (default Linux build relies on landlock read-only system
   dirs), but the static gate is confirmed-bypassable.

## Root cause

1. The 38.3/43.18 blocking sweep was tool-name based (grep, web_fetch) and
   missed glob and computer_use.
2. `std::thread::sleep` used where `tokio::time::sleep` belongs.
3. The redirection gate matches literal bytes without shell-glob expansion.

## Approach

1. glob.rs: wrap the `WalkBuilder` iteration in `spawn_blocking`.
2. computer_use.rs: replace `std::thread::sleep` with `tokio::time::sleep`.
3. bash_safety.rs: expand shell glob/character-class targets before the
   dangerous-prefix match (or deny redirections whose target contains unexpanded
   metacharacters) so the gate cannot be escaped. Add pinning tests.
