# WO 43.4 — Property-based tests for the path-safety surface

## Status: Planned

## Problem

The path-safety module is `crates/kf-routing/src/path_safety.rs` (NOT
`src/tools/path_safety.rs` as the backlog sketched). It has ~45 example-based
unit tests (`path_safety.rs:631-1084`), so "untested" overstates — but these
branches have ZERO tests:

- `segments_have_escaping_symlink` (`path_safety.rs:260`) — the intermediate
  symlink-escape walk; no test creates a symlink anywhere in the file.
- `final_file_is_symlink` (`path_safety.rs:304`) — no test.
- `write_artifacts` deny_paths branch (`path_safety.rs:540-557`) — no test.
- `write_artifacts` size limit (`path_safety.rs:500`) — no test.
- `write_artifacts` binary-content block (`path_safety.rs:511`) — no test.

The sibling surface `PathGuard` (`src/shared/access/mod.rs`, tests at :651+)
is well covered. The adversarial input space here (traversal, symlinks,
unicode) is combinatorial; hand-picked vectors cannot enumerate it.

proptest is ALREADY a root dev-dependency (`Cargo.toml:251`, `proptest = "1.6"`,
comment: "Property-based testing for edit-file diff application") and in
`crates/kf-compress-core/Cargo.toml:20`. Not a new workspace dependency —
one dev-dep line for this crate, zero binary impact.

## Root cause

Example-based tests pin fixed vectors; no property (for-all) coverage exists
for the pure path predicates, and five guard branches ship untested.

## Approach

1. Add `proptest = "1.6"` to `crates/kf-routing/Cargo.toml` `[dev-dependencies]`.
2. Add a `proptest!` module inside `path_safety.rs`'s existing `mod tests`:
   - P1 traversal: strategy = random segment vectors with injected `..`/`.`/
     absolute prefixes; assert `is_inside_cwd` false whenever the normalized
     path escapes cwd, and `safe_relative_path` returns `None`.
   - P2 absolute injection: `/etc/x`, `C:\x`, `C:/x` → `is_absolute_path`
     true; pin current UNC behavior (`\\srv\share` is NOT detected by
     `is_absolute_path:61-70` — backslash lead misses both checks; containment
     step 1 still blocks it; pin as documented finding, do not fix here).
   - P3 no-panic: arbitrary `String` incl. `\0` bytes and mixed separators —
     predicates never panic and return a verdict.
   - P4 NFC/NFD: same path in NFC vs NFD must get identical containment
     verdicts; note deny_paths matching (`path_safety.rs:548`, byte compare) is
     normalization-sensitive — honest-doc note in the test, fix deferred.
   - P5 symlink fixtures: fixed fixture tree (one segment a symlink pointing
     outside cwd, one inside) + property over random relative sub-paths;
     assert `segments_have_escaping_symlink` fires only for the escaping ones
     and `final_file_is_symlink` blocks the terminal-symlink case. Unix-only
     (`#[cfg(unix)]`).
3. Commit any proptest regression files (`proptest-regressions/`) that appear.
