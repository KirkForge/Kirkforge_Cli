# WO 45.16 — Split `src/session/config/mod.rs` (2952 lines / 120477 bytes)

## Status: Planned

## Problem

`src/session/config/mod.rs` is the largest source file in the workspace at
**2952 lines / 120477 bytes** (verified via `wc -l` / `wc -c`). It mixes three
distinct concerns behind one module door:

1. **Config bootstrap** — `load_config`, `load_or_create_config` (+ strict
   variant), `save_config`, `freeze_launch_sandbox`, legacy path handling
   (lines 1–384, ~380 lines).
2. **TOML→Config merge** — `merge_toml_into_config`, a 436-line field-by-field
   merge function (lines 389–825). This is the single largest function in the
   file and the reason the file crossed 2000 lines.
3. **Diff summary + plugin-sources env parse** — `config_diff_summary`
   (lines 830–971, ~145 lines) and `parse_plugin_sources_env` (lines 973–997).
4. **Inline tests** (lines 1000–2952, ~1950 lines — the bulk of the file is
   tests, which is fine, but the non-test code is still ~1000 lines across
   three concerns).

The `env_overrides` submodule (line 60) is already extracted. The remaining
merge + diff logic has not been split.

## Root cause

`merge_toml_into_config` grew field-by-field as `Config` acquired fields
across WOs 22–44. No boundary was ever drawn between "bootstrap/load" and
"merge/diff", so the file accreted to 2952 lines. The merge function alone
(436 lines) is larger than many complete modules in this repo.

## Approach

Opportunistic extraction (no behavior change, pure code movement):

1. **`merge.rs`** (new, ~450 lines) — move `merge_toml_into_config` and its
   `expand_tilde_str` helper (used only by merge + load). Re-export from
   `mod.rs` via `use merge::merge_toml_into_config;` so `load_config` is
   unchanged.
2. **`diff.rs`** (new, ~170 lines) — move `config_diff_summary` and
   `parse_plugin_sources_env`. Both are pure functions over `Config` with no
   dependency on the bootstrap path.
3. **`mod.rs`** keeps: module docs, `load_config`, `load_or_create_config`*,
   `save_config`, `freeze_launch_sandbox`, `legacy_config_path`,
   `env_overrides` wiring, `parse_bool_env`, and the inline `tests` module.
   Target: ~1000 lines (non-test) + tests.

Move the corresponding test fns into the new submodules' `#[cfg(test)]`
modules so each test sits next to the code it exercises.
