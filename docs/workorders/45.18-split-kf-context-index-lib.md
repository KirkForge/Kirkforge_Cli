# WO 45.18 — Split `crates/kf-context-index/src/lib.rs` (2706 lines / 103356 bytes)

## Status: Planned

## Problem

`crates/kf-context-index/src/lib.rs` is **2706 lines / 103356 bytes**
(verified via `wc -l` / `wc -c`). It already has two submodules
(`embeddings.rs`, `graph_walk.rs`), but `lib.rs` itself still holds:

1. **Core types** — `SymbolKind`, `Language`, `Symbol`, `ImportEdge`,
   `CallEdge`, `CallSite`, `RetrievalResult`, `CachedIndex` (lines 1–132,
   ~130 lines).
2. **`ContextIndex` struct + constructors** — `new`, `from_symbols*`,
   `from_cached` (lines 150–230, ~80 lines).
3. **Tree-sitter parsing** — `index_file`, `extract_import_edges`,
   `extract_call_edges`, `extract_callee_name`, `last_identifier`,
   `find_enclosing_function`, `walk_tree` (200+ lines), `try_extract_ts_arrow`,
   `is_python_dunder_main_guard`, `try_extract_go_method`,
   `find_go_receiver_type`, `extract_doc_comment`, `dedup_interfaces`,
   `extract_import_specifier` (lines 231–967, **~740 lines** — the bulk).
4. **Resolution** — `resolve_imports`, `resolve_call_edges`, `is_ignored_dir`,
   `index_dir` (lines 968–1048, ~80 lines) + free-fn `resolve_import`
   (lines 1465–1569, ~105 lines).
5. **Retrieval** — `retrieve`, `retrieve_symbols`, `retrieve_hybrid`,
   `to_retrieval_result` (lines 1058–1200, ~140 lines).
6. **Cache I/O** — `save`, `load`, `is_current`, `incremental_rebuild`,
   `mtime_rebuild`, `current_head`, `git_diff_files`, `extract_quoted_string`
   (lines 1201–1569, ~370 lines).
7. **Inline tests** (lines 1570–2706, ~1140 lines).

## Root cause

The tree-sitter parser (`walk_tree` + per-language extractors) and the cache
I/O layer accreted inside `ContextIndex`'s impl block across phases 6–7 and
WO 43.21. The parser alone is ~740 lines — bigger than `embeddings.rs` and
`graph_walk.rs` combined — yet never got its own module.

## Approach

Opportunistic extraction (no behavior change, pure code movement):

1. **`parser.rs`** (new, ~750 lines) — move all tree-sitter extraction:
   `walk_tree`, `try_extract_ts_arrow`, `is_python_dunder_main_guard`,
   `try_extract_go_method`, `find_go_receiver_type`, `extract_doc_comment`,
   `extract_import_edges`, `extract_call_edges`, `extract_callee_name`,
   `last_identifier`, `find_enclosing_function`, `dedup_interfaces`,
   `extract_import_specifier`. These are private fns called only by
   `index_file`; make them `pub(super)` or pass the index as a mutable ref.
2. **`resolve.rs`** (new, ~200 lines) — move `resolve_imports`,
   `resolve_call_edges`, `is_ignored_dir`, `index_dir`, and the free fns
   `resolve_import`, `extract_quoted_string`.
3. **`cache.rs`** (new, ~380 lines) — move `save`, `load`, `is_current`,
   `incremental_rebuild`, `mtime_rebuild`, `current_head`, `git_diff_files`.
   These are I/O over `CachedIndex` / disk, cleanly separable.
4. **`lib.rs`** keeps: core types, `ContextIndex` struct + constructors,
   retrieval methods, `pub mod` declarations + re-exports, inline tests.
