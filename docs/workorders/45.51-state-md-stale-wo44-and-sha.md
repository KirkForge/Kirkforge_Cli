## Status: Planned

## Problem

`state.md` (tracked, the repo-state source of truth) has two stale claims that
contradict both `git log` and the WO file headers.

1. **WO 44 series listed as Pending, but it is Done.**
   - `state.md:86` (under "## Pending / Deferred (open)") says:
     `**WO 44 series (25 items)**: the next phase. Highest risk first: 44.20
     (bash \`&\` allowlist bypass), 44.22 (Anthropic key → ollama_host), 44.36
     (executor death-spin), 44.52 (PR CI silent skip). Full list in
     [44.0](docs/workorders/44.0-wo44-overview.md).`
   - Reality: `docs/workorders/44.0-wo44-overview.md` file header reads
     `## Status: Done`. Commit `e32c08b5` ("docs(wo44): sync README rows for
     wave 4 Done WOs; full gate green (4953 passed) — WO 44 series complete")
     closes the series. The workorders/README.md index marks every 44.* row
     Done (44.0 through 44.56, verified at
     `docs/workorders/README.md:897-922`). The "Highest risk first" prose
     describes work that has all shipped.
   - Evidence: `git log --oneline | grep "WO 44 series complete"` →
     `e32c08b5 docs(wo44): sync README rows for wave 4 Done WOs; full gate
     green (4953 passed) — WO 44 series complete`.

2. **HEAD SHA is stale.**
   - `state.md:174` says `**main == dev == origin/main == origin/dev** at
     \`138adff8\`.` and `state.md:189` says `Last full local gate on
     \`138adff8\`: test-full 4905 passed...`.
   - Reality: `git rev-parse HEAD` → `aec47bfe`. `138adff8` is an ancestor
     commit ("fix(ci): cfg(unix) run_bash_stuck_step_times_out — Windows leg
     deferred to WO 44.44"); the WO 44 wave-4 work and the AGENTS.md branch-flow
     reinstatement (`aec47bfe`) landed after it. The "CI / branch state"
     section describes a snapshot from the prior session, not the current
     tree.

## Root cause

The WO 44 series was closed in a later session (commit `e32c08b5`,
"WO 44 series complete") than the session that wrote the current `state.md`
block. `state.md` was not refreshed on WO 44 close — the "Shipped" section
mentions "WO 44 series created" (line 36) but the "Pending" section (line 86)
was never moved to "Shipped" when the series completed. The HEAD SHA was
pinned at the last session's close and never updated when the WO 44 wave-4
landed. This is the classic interrupted-session residue pattern called out
in AGENTS.md §7 ("Interrupted sessions leave three-part residue").

## Approach

Move the WO 44 series entry from "## Pending / Deferred (open)" to "##
Shipped (closed this session)" with a one-line summary mirroring the
`e32c08b5` commit message. Update the HEAD SHA references
(`state.md:174`, `state.md:189`) from `138adff8` to the current HEAD
(`aec47bfe` or whatever is current at edit time — re-run `git rev-parse
HEAD`). Optionally note the WO 44 wave-4 gate count (4953 passed) if the
"Last full local gate" line is updated. Keep the per-WO deferral tails
that are still genuinely open (e.g. `KF_CODE_DAEMON_ROLE` none, WO 43.x
deferred tails) — only the "WO 44 series (25 items)" line moves.

Do NOT touch the "Known flakes", "Architecture notes", or the
WO 43.x deferred-tail bullets — those are still accurate.
