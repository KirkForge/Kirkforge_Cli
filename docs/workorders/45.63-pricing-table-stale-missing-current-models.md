# WO 45.63 — Pricing table is stale; missing all current Anthropic model families

## Status: Planned

## Problem

`PRICING_TABLE` (`src/shared/mod.rs:770-870`) has entries through
`claude-opus-4`, `claude-sonnet-4`, `claude-haiku-4`, plus 3.x legacy
rows and GPT rows — nothing for `claude-sonnet-5`, `claude-opus-4-8`,
`claude-haiku-4-5`, or any newer model family.

The fallback is longest-prefix matching with a sentinel `model_prefix:
""` entry (rates all 0.0) plus a `warn_unmapped_model` log line. So:
- `claude-opus-4-8` partially matches `claude-opus-4` prefix → gets
  OLD Opus-4 pricing (wrong rates, not $0)
- `claude-sonnet-5` matches nothing → falls to $0 with a warning

Cost tracking doesn't lie (it warns), but it silently underreports for
unmapped models and misreports for partial-match models. The warning is
log-only — not surfaced in the TUI — so nobody notices until a bill
doesn't match.

## Root cause

Same as WO 45.62: model-identity logic hardcoded to specific name
strings. The pricing table requires a manual update every time a model
is released. The partial-match issue (`claude-opus-4-8` matching
`claude-opus-4`) is a design flaw in longest-prefix matching when newer
models in the same family have different pricing.

## Approach

1. Add pricing rows for current Anthropic model families
   (`claude-sonnet-5`, `claude-opus-4-8`, `claude-haiku-4-5`, etc.).
   Verify rates against Anthropic's current pricing page.
2. Make the $0-fallback louder: surface the `warn_unmapped_model` warning
   in the TUI status bar (or as a session-startup check) so the user
   knows cost tracking is incomplete for their model.
3. Consider: change the matching from longest-prefix to exact-model-id
   lookup with a family-level fallback, so `claude-opus-4-8` doesn't
   silently inherit `claude-opus-4` pricing.
4. Add a test that verifies every model name in the `supports_thinking`
   capability table (WO 45.62) has a pricing entry — cross-DRIFT between
   the two tables.

## Files

- `src/shared/mod.rs` (PRICING_TABLE + matching logic)
- `src/tui/` (surface unmapped-model warning — find the right widget)

## Gate

`scripts/test-fast.sh` + `cargo clippy --all-targets -- -D warnings` +

(non-zero) pricing; unmapped models surface a visible warning.
