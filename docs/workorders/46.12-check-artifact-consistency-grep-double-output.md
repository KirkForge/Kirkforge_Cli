## Done

Fixed: `scripts/check-artifact-consistency.sh:90` — `|| echo 0` → `|| true`.

**Root cause:** `grep -c` on a zero-match file prints `0` to stdout AND exits
1. The `|| echo 0` fallback then appended a second `0`, so the command
substitution captured `0\n0` (two lines). The downstream
`[ "$TECHNICAL_ROWS" -eq "$EXPECTED_BENCHES" ]` saw the literal `0\n0` and
threw "integer expression expected" under `set -euo pipefail`, killing the
script as a false failure (even when TECHNICAL.md row count was actually
correct).

**Fix:** `|| true` swallows the non-zero exit without producing extra
output — `grep -c` already prints `0` on no-match, so the capture stays a
single `0`. Matches the existing pattern at lines 19, 43, 109, 110 (all use
`|| true`).

exit 0 + `scripts/test-fast.sh` (4765 passed, 15 skipped, exit 0 via
