## Done

`delegate.rs:301` wrote `outcome: Some(decision.mode.as_str().into())` — the
routing mode ("artifact"/"hard-prompt"/"schema-contract"/"task-decompose"),
not a verdict. `normalize_outcome` (kf-routing/src/routing.rs:124) maps any
non-pass/fail/error string to "error", so every observation landed in the
neutral "error" bucket and the empirical router learned zero pass/fail signal.

Root cause: the wrong field was stored. The actual task result was already
computed two lines above by `reduce_result` (delegate.rs:279) and stored in
`result.packet.verification.overall` (an `OverallVerdict` enum: Pass/Fail/Warn/
Unknown). The fix maps that verdict to the empirical router's bucket:
  Pass → "pass" (reward), Fail → "fail" (punish), Warn/Unknown/absent → "error"
  (neutral). The reducer (ADR-076) never emits Unknown, and a Warn is a
  qualified pass — neither reward nor punish is correct, so "error"/neutral
  is the honest bucket.

Change: `crates/kf-orchestrator/src/delegate.rs` — replaced the mode-as-outcome
write with a verdict-as-outcome write (~10 lines, smallest correct diff). The

extended to assert `outcome == "pass"` (it routes to schema-contract, which
