# WO 46.19 — Daemon state mutex held across write_response .await — single wedged client stalls whole daemon

## Status: Done

## Problem

**Location:** `src/daemon/server.rs:221-253`

InstanceRegister acquires state.lock().await (line 221), then calls write_response(&mut stream, ...).await while still holding the guard on all three error paths. A client that sends an invalid token then stops reading stalls the flush → the single global state mutex stays held. Every other op blocks. Fix: drop the guard before writing the response.

## Done

`src/daemon/server.rs:221-256` (InstanceRegister handshake) now builds
the error `Response` (auth fail / RBAC deny / version mismatch) under
