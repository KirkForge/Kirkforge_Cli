# WO 46.20 — Never-ending bash job blocks scheduler and graceful shutdown — unshutdownable daemon

## Status: Planned

## Problem

**Location:** `src/jobs/daemon.rs:146-197`

run_bash_job polls registry.get(id) until the job leaves Running. If job.timeout is None (default unset), a bash job that never exits keeps Running forever. The daemon blocks on handles await at daemon.rs:190 and sem.acquire at daemon.rs:152. SIGTERM/SIGINT/Shutdown only fires shutdown.notify_one(), but nothing awaits it while the loop is stuck. Process only dies via SIGKILL. Fix: enforce a default timeout on all scheduled jobs.
