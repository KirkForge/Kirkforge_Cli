## Status: Done

## Fix

into `handle_bench_run_models`, placed after the per-model reports +
comparison are written (same artifact-preserving ordering as the
single-model guard). Bails with `bench run-models: model <name> got
0/N tasks passed (0%)` if any report has `tasks_run > 0` and
`tasks_passed == 0`. Routes through the error classifier (General →
exit 1) so CI can detect total failure.
