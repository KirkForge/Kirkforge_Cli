# WO 46.3 — Daemon concurrency semaphore starved by long-lived instance push channels

## Status: Planned

## Problem

**Location:** `src/daemon/server.rs:75,107,254`

Semaphore::new(16) permit is held for the entire handle_client lifetime, including long-lived InstanceRegister push channels. 16+ connected TUI instances permanently consume all permits, blocking new connections (e.g. kf-code run --attach). Fix: release the permit before entering the push loop for instance connections.
