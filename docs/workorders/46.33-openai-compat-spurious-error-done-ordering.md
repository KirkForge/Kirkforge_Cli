# WO 46.33 — openai_compat spurious Error on DONE-before-finish_reason ordering

## Status: Done

## Problem

**Location:** `src/adapters/openai_compat/mod.rs:260-290`

The [DONE] branch flushes pending_tool_calls via drain and emits Done. If a proxy then sends finish_reason:tool_calls frame after [DONE], the finish_reason handler evaluates pending_tool_calls.is_empty() (now true) and emits a spurious Error. The executor sees an error on a successfully-parsed tool-call turn.
