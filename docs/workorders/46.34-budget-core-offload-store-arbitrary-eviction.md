# WO 46.34 — kf-budget-core InMemoryOffloadStore evicts arbitrary entries, not oldest

## Status: Done

## Problem

**Location:** `crates/kf-budget-core/src/store.rs:112-126`

Docstring says 'Remove the oldest entries' (FIFO), but implementation does guard.keys().take(excess) on a HashMap whose iteration order is arbitrary. A just-inserted entry may be dropped while an old one survives. Fix: use a VecDeque or IndexMap for FIFO ordering.
