# WO 46.35 — Parallel tool batches leave a ghost streaming card and mis-pair result entries

## Status: Planned

## Problem

**Location:** `src/tui/events.rs:195-216`

When the model requests multiple tool calls in one turn, ToolStart placeholders are pushed back-to-back. When ToolResult A arrives, dispatch_turn_event checks last.streaming (true for B's still-open placeholder), pops B's card and substitutes A's result. B's placeholder is never popped. Ghost card corruption; common for multi-file edits.
