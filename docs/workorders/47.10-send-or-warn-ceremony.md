# WO 47.10 — send_or_warn! ceremony → single emit! macro (47 sites × 4-6 lines)

## Status: Done

## Problem

send_or_warn! is invoked at 47 sites, each with 4-6 lines of surrounding ceremony. A single emit! macro collapses ~175 lines. Cosmetic but mechanical.

Source: post-WO-46 size audit (kf-code-review.md, 2026-08-27). The codebase is
~110K production lines vs a ~30K lean-agent baseline; this WO is part of the
"Lean KirkForge" convergence toward ~85-88K.

## Root cause

Accumulation across WO series — features added per-WO with default features
and no size gate at add/remove time; crate boundaries drawn early never
revisited; process artifacts (tests, docs, dev tooling) counted as codebase.

## Approach

Read the Problem section. Implement the minimal correct reduction. Where a WO
deletes code, verify no production consumer breaks (grep + cargo check).
Where it moves code, keep public APIs stable or update all consumers.

## Files

src/shared/mod.rs, callers across src/

## Gate

`scripts/test-fast.sh` + `cargo clippy --all-targets -- -D warnings` +
`cargo fmt --check` + `cargo check --workspace --all-targets`. For deletions:
`git grep` proves zero production references before removal.

## Done

Implemented on `wo/wo47.10` (2026-08-28).

- New `emit!` macro in `src/shared/mod.rs` (2-arg form defaults to the
  exact message all 41 TurnEvent sites repeated; 3-arg form passes a
  custom message). Expansion is identical to the old inline
  `send_or_warn!` wrapping — no behavior change.
- The WO's "47 sites" = the async `event_tx.send(TurnEvent::…).await`
  sites; actual count 46: turn.rs 24, outcome.rs 8, dispatch.rs 5,
  loop_.rs 3, model.rs 6 (custom "TUI dropped …" messages preserved via
  the 3-arg form). All rewritten mechanically.
- The other 29 `send_or_warn!` sites are sync sends (unbounded mpsc /
  oneshot, no `.await`, already 1-3 lines) — out of scope, untouched.
  A single macro cannot cover both shapes: `.await` on a `Result` does
  not compile and macro_rules cannot branch on awaitability.
- Net −100 lines (322 del / 222 ins incl. the 15-line macro + fmt
  rewrap; pre-fmt the raw ceremony removal was ~300 lines).
- Gate (fast, per worker prompt; head see commit): `cargo check
  --workspace --all-targets` EXIT=0 (12m59s, load ~10); `cargo clippy
  -p kf-code --all-targets -- -D warnings` EXIT=0 (8m45s);
  `cargo nextest run -p kf-code --lib --bins -E 'test(/executor/) +
  test(/model/) + test(/shared/)'` 716/716 passed; `cargo fmt --check`
  clean. Full suites not run (parallel-wave worktree, fast gate only).
