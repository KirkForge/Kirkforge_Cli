## Problem

CRITICAL. WO 46.32 fixed the session daemon (SHA-256 hash before ct_eq at daemon/mod.rs:449; set_permissions(0o600) at server.rs:71-77) but src/jobs/daemon.rs has its own private check_auth (line 262-277) still doing raw ct_eq (length leaks) and its own UnixListener::bind (line 79-88) without perms (0o755 default — any local user can connect and call Shutdown).
