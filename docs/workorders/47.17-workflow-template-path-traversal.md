## Problem

HIGH — sandbox escape. WorkflowTool::run (src/tools/workflow.rs:90) takes template from model tool-call JSON with only a non-empty check. find_workflow_file (crates/kf-workflow/src/discovery.rs:8) does PathBuf::join(format!("{name}.json")) — (1) an absolute template ('/tmp/evil') discards the base entirely (join semantics); (2) '../../..' segments walk out. The loaded file executes as a fully-trusted Workflow (spawns subagents, runs bash steps). Fix: validate template as a bare filename — reject '/', '\\', '..', and leading '/' before any PathBuf::join; same for the shared data-dir lookup.
