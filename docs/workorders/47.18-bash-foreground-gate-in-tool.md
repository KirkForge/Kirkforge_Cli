# WO 47 — Bash tool foreground path has no safety gate — direct callers bypass pre_run

## Status: Done

## Problem

HIGH — defense in the wrong layer. check_bash_command_str for the foreground path lives only in the executor's pre_run (src/session/executor/pre_run.rs:219). The tool itself gates only docker (bash.rs:116) and dry-run (bash.rs:319). Direct tool.run() callers — workflow `tool:` steps (src/tools/workflow.rs:443-460 builds a ToolContext and calls tool.run directly), plugins, /replay — execute model-authored commands unchecked. Fix: call check_bash_command_str inside Bash::run's foreground branch (as docker/dry-run already do); keep pre_run as fast-fail. Verified: workflow.rs run_tool never passes through pre_run.
