# WO 47 — panic=abort makes every catch_unwind containment guard dead code in release — contract drift

## Status: Done

## Problem

HIGH — honest-doc decision needed. [profile.release] panic = "abort" (Cargo.toml:364) means panics ABORT; the catch_unwind guards at verifier/bus.rs:169, handler.rs:130, executor/dispatch.rs:750, kf-budget-core/paths.rs:337 never fire in production. The documented contract 'a panicking tool returns a clean Failure' (dispatch.rs:741) is FALSE in release. Tests build with unwind so no test catches it. state.md pins keep-abort for binary size. Fix (pick one, keep docs honest): (a) remove panic=abort so catch_unwind works; or (b) keep abort, delete the dead wrappers, replace the contract comment with a ponytail:/ceiling: note.
