# WO 47 — Adapter wire fixes: Bedrock content-length signing, SSE line-anchoring, /v1 over-trim, Vertex URL-encoding

## Status: Planned

## Problem

HIGH (correctness). (1) Bedrock SigV4 omits content-length from the signed headers (mm-H13; wiremock matcher hides it — real AWS can reject). (2) anthropic/sse.rs + openai_compat scan for the 'data: ' SUBSTRING anywhere in the buffer, not line-anchored (mm-H14) — a payload containing that substring inside JSON is parsed as a frame (the 44.23 fix covered Bedrock error frames only). (3) openai_compat trim_end_matches("/v1") erases LEGITIMATE repeated segments like /v1/v1 configs and doesn't de-dup in with_base_url_and_key (mm-H15/H16 — 44.22's strip_suffix fix was applied at one construction site only). (4) Vertex builds URLs by string-formatting model_id/project_id/region with no percent-encoding (mm-H17) — a model id with '/' or '?' corrupts the URL. Fix all four; add wire-level tests per site.
