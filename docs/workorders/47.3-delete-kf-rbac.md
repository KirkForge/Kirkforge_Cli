# WO 47.3 — Delete the dead JWT/JWKS half of kf-rbac (keep the live RBAC core)

## Status: Planned

## Problem

`kf-rbac` is two subsystems with different liveness:

- **Live and load-bearing** (`rbac.rs` 389 + `api_key.rs` 55 + `error.rs` 75):
  the role/permission model (`Actor`, `Role`, `Permission`, `has_permission`,
  `actor_from_api_key`) gates ~9 daemon call sites (WO 43.6) via
  `actor_for_token` + `KF_CODE_DAEMON_ROLE`. Deleting this would rip out the
  daemon's authorization layer. **NOT in scope.**
- **Dead** (`jwt.rs` 462 lines): JWT validation + JWKS fetch/cache. Zero
  production consumers — no `use kf_rbac::jwt` anywhere in `src/` or other
  crates (grep-verified). It was built for a multi-tenant daemon future that
  the single-token + role-file model superseded.

AMENDED 2026-08-27 after owner challenge: the original version of this WO
said "delete kf-rbac" wholesale — a size-audit overreach that missed that
the RBAC half is the daemon's live authz. Scope is now the dead JWT half
only.

## Root cause

The JWT path was ported (kf-rbac is a memory-palace port) before the daemon
settled on token+role auth (WO 43.6). The dead half shipped and stayed
because nothing fails when unused code exists behind a clippy-clean gate.

## Approach

1. Delete `crates/kf-rbac/src/jwt.rs` + its `pub use jwt::…` re-exports in
   `lib.rs` (lines 11-14).
2. Delete the JWT-specific tests (the ES512 `#[ignore]` in
   `crates/kf-rbac/tests/jwt.rs` and its file if fully JWT-scoped).
3. Keep `rbac.rs`/`api_key.rs`/`error.rs` and the crate itself — the daemon
   consumes them.
4. Update `docs/TECHNICAL.md` RBAC section (doc-sync rule) and the state.md
   43.6 entry if it mentions JWT.
5. Check `docs/adr/` for a JWT-related ADR — amend its status if it claims
   the JWT path is live (ADR status is two-source-of-truth with the index).

## Files

- crates/kf-rbac/src/jwt.rs (delete)
- crates/kf-rbac/src/lib.rs (re-export trim)
- crates/kf-rbac/tests/jwt.rs (delete if fully JWT-scoped)
- docs/TECHNICAL.md, docs/adr/ (if a JWT ADR exists)

## Gate

`git grep kf_rbac::jwt` → zero hits after deletion.
`git grep jwt` in crates/kf-rbac → only historical comments remain.
`scripts/test-fast.sh` + `cargo clippy --all-targets -- -D warnings` +
`cargo fmt --check` + `cargo check --workspace --all-targets`.
Daemon tests (server.rs auth/RBAC suite) stay green.
