# WO 47 — write_file parent-dir TOCTOU + permission glob matcher catastrophic backtracking

## Status: Done

## Problem

MEDIUM. (1) src/tools/write_file.rs:112-166 — check_write canonicalizes the parent, then create_dir_all + atomic_write use the LITERAL path; a symlink swapped into the parent between check and rename redirects the write outside the sandbox (atomic_write's O_EXCL protects the temp file, not the directory). Fix: re-canonicalize and re-verify immediately before rename, or write relative to the canonicalized dir from the verdict. (2) src/shared/permission.rs glob_match_recurse — multiple overlapping ** patterns backtracking combinatorially (**a**a**a vs aaaa...) on the tool-call hot path; shared/plugin-influenced config could DoS every call. Fix: linear DP/NFA matcher (keep semantics identical — the proptest suite pins them).

sonnet-bugs.md, gpt-bugs.md). Top-severity claims verified against the code at

## Done

Both defects fixed on `wo/wo47.34` (not merged/pushed — parallel-wave
worktree), one gated commit each:

1. **write_file TOCTOU** (`13ffe763`, src/tools/write_file.rs): the
   destructive write is now anchored to
   `canonicalize(parent)/file_name` — at rename time only the file
   name is resolved, never an ancestor symlink — and the guard re-runs
   `check_write` on the anchored path immediately before the rename,
   so a swap made before canonicalization is denied. Messages/undo
   keep the literal path (Windows `\\?\` verbatim paths never leak).
   Degenerate paths (no file name) fall back to the literal path,
   which the re-verify still covers. 3 new tests: anchoring unit test,
   e2e write-through-symlinked-parent (lands in real dir, no temp
   residue), and a deny-list proof that a canonical-path deny pattern
   blocks a symlink-alias write the first (literal) check let through.
   Testability ceiling: the check→rename race itself is not unit-
   testable without injection hooks; the deny-list alias test pins the
   re-verify, the anchoring tests pin the non-re-traversal.
2. **glob matcher** (`0e588704`, src/shared/permission.rs):
   `glob_match_recurse` replaced by a tokenized NFA state-set
   simulation, O(|pattern| × |value|) — no state re-exploration, so
   overlapping `**` runs cannot backtrack combinatorially. Semantics
   identical (proof: maximal star run of 1 = `[^/]*`, run of ≥2 =
   `.*` — a 3+ run parses pairwise as `.*` + star tokens whose
   languages all contain ε, so the run is exactly Σ*; `?` = `[^/]`;
   literals exact — same language, same booleans). Equivalence
   evidence: 104/104 module tests (all pinned edge cases: `a/**/b`,
   `**/foo.rs` vs `foo.rs`, `*/*`, `foo**bar`, `***`, UTF-8, empty
   pattern, `?`-no-slash) + the proptest suites (determinism/totality
   ASCII+Unicode, `**`-anything, `*`-respects-slash, long-inputs)
   green; plus an exhaustive cross-check of old-vs-new over all
   patterns ≤5 chars ({a,/,*,?}) × values ≤5 chars ({a,b,/}) =
   496,860 pairs, 0 mismatches (scratch script, not committed). New
   regression test pins the pathological input (`**a**a**a**b` vs
   200 a's — Θ(n⁴) before, instant now).

Fast gate (head `0e588704`+): cargo check --workspace --all-targets,
clippy -p kf-code --all-targets -D warnings, permission proptest
suite, fmt --check — outputs pasted in the session report.
