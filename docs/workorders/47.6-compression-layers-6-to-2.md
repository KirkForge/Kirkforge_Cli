# WO 47.6 — Six live compression layers → two (stratum modes should map to 2 pipelines)

## Status: Done

## Problem

Six compression layers are live (micro, budget-slice, LLM summarize, findings-pin, + 2 more). The Off/Lite/Full/Ultra stratum modes should map onto at most 2 underlying pipelines with parameter differences (~2.5K lines). Consolidate without losing the mode semantics. AGENTS.md §7 forbids unifying the two verifier traits — this WO is compression only.

Source: post-WO-46 size audit (kf-code-review.md, 2026-08-27). The codebase is
~110K production lines vs a ~30K lean-agent baseline; this WO is part of the
"Lean KirkForge" convergence toward ~85-88K.

## Root cause

Accumulation across WO series — features added per-WO with default features
and no size gate at add/remove time; crate boundaries drawn early never
revisited; process artifacts (tests, docs, dev tooling) counted as codebase.

## Approach

Read the Problem section. Implement the minimal correct reduction. Where a WO
deletes code, verify no production consumer breaks (grep + cargo check).
Where it moves code, keep public APIs stable or update all consumers.

## Files

src/session/prompt/**, crates/kf-compress-core/**

## Gate

`scripts/test-fast.sh` + `cargo clippy --all-targets -- -D warnings` +
`cargo fmt --check` + `cargo check --workspace --all-targets`. For deletions:
`git grep` proves zero production references before removal.

## Done

Shipped the smallest safe consolidation (zero behavior drift — every
output byte identical; all 146 prompt-module + 74 compact-consumer tests
green unchanged):

1. **Tool-result stub marker single-sourced.** `mod.rs`'s private
   `TOOL_RESULT_STUB` const duplicate deleted; both stub sites
   (`compact_to_budget` middle region and
   `PromptBuilder::stub_old_tool_results`) now use
   `compaction::TOOL_RESULT_STUB` + the new shared
   `compaction::stub_tool_result()` helper (marker + `token_count=None`
   + keeps tool_name/tool_call_id).
2. **Anchor/region split shared.** New `compaction::anchor_len()`
   replaces the duplicated leading-system-anchor detection in
   `compact_to_budget` and `maybe_microcompact`.
3. **Token-estimator copies deleted.** microcompaction.rs's
   `estimate_message_tokens`/`estimate_tokens` delegates and
   summarizer.rs's `estimate_token_count` delegate removed; all call
   the shared `prompt::estimate_message_tokens`/`estimate_tokens`.
   One duplicate vacuous test (`estimate_tokens_empty_is_zero`, also in
   compaction.rs tests) deleted with them.

Verified: stratum side already conforms to the 2-pipeline target —
kf-compress-core is ONE `CompressionPipeline` with Off/Lite/Full/Ultra
as parameter differences (`runs_transforms`/`offloads_bloat`); no edit
needed there.

**DEFERRED (structural 6→2)**: folding `maybe_microcompact` +
`compact_to_budget` behind one middle-strategy enum, wiring
`summarize_conversation` as that strategy's LLM arm at the `/compact`
call site, and collapsing the 3-rung request-build fallback ladder
(minify → stub → truncate) into strategy-escalation parameters.
- **Why deferred**: the executor call site (`loop_.rs:292-494`) and the
  TUI `/compact` command are outside this WO's named file scope
  (`src/session/prompt/**`, `crates/kf-compress-core/**`); the ladder
  rungs' interactions are pinned by tests only at the outer-contract
  level (WO 43.29 no-panic test, R3/R4 series), and this worker ran
  fast gates only (no test-full) — cross-cutting strategy rewrites
  under that verification budget are exactly the behavior-drift risk
  the worker prompt cautions against.
- **Exact remaining work**: (a) add a `MiddleStrategy` enum
  (CollapseToSummary | StubPerSlot) to compaction.rs with
  `(keep_tail, budget)` params; (b) reimplement `maybe_microcompact`
  and `compact_to_budget` as thin wrappers over one shared
  anchor/middle/tail driver; (c) at `loop_.rs`'s compact handler, route
  summarize→naive through the same strategy (LLM arm); (d) re-express
  the `build_messages_with_compaction` rungs as one escalation loop.
  Each step gated by the existing R3/R4 + prompt test suites plus
  test-full.
