# WO 48 — fallback_c_like inserts a space after every colon — std::cout becomes std: : cout on disk write-back

## Status: Planned

## Problem

P1. src/shared/minify/expand.rs:362-375 — the fallback formatter's ':' arm inserts a space after EVERY colon; C/C++/Java have no external formatter arm, so every envelope write-back in those languages writes non-compiling code to disk (std::cout → std: : cout, use std::… → use std: : …). Untracked since expand.rs was created. Fix: only pad around :: used as a scope-resolution/namespace separator is hard to detect — simplest correct: don't pad after a colon unless followed by another colon (the :: case gets one space around the PAIR), and never pad a colon adjacent to identifier chars on the inside. Test: std::cout, use std::io, http:// in strings, ternary a ? b : c all round-trip byte-identical.
