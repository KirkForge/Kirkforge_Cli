# WO 48.38 — fallback_c_like has no backtick arm — re-expansion corrupts Go raw strings / JS template literals

## Status: Done

## Problem

P2. src/shared/minify/expand.rs:270 — fallback_c_like tracks `"`/`'` string
state but not backticks, so on minified-envelope write-back the `;`/`{`/`,`/
newline arms fire INSIDE backtick literals (Go raw strings, JS template
literals), inserting newlines/spaces into literal text. Untracked since
expand.rs was created. The minifier half (minify_js_like, lang.rs:762) DOES
track backticks and emits verbatim — the two halves of the round-trip used
different state machines.

Source: Sweep 4 (2026-08-29).

## Root cause

Expander state-machine drift vs. the minifier: minify_js_like treats
`` ` `` as a string delimiter; fallback_c_like did not. Round-trip fidelity
requires both scanners to agree on where the literal ends.

## Approach

Add `` ch == '`' `` to the string-open condition in fallback_c_like. The
existing in_string branch then emits verbatim until the closing backtick
with the same `\`-escape rule the minifier uses, so both sides agree.
Other fallback arms checked: py is line-based indent only; rb/sh map to
normalize_trailing_newline (no punctuation insertion) — no backtick hazard.

src/shared/minify/expand.rs

## Gate

## Done

- String-open condition in `fallback_c_like` (src/shared/minify/expand.rs):
  `"` / `'` / `` ` `` — backtick literals emitted verbatim to the closing
  delimiter, mirroring minify_js_like's scanner exactly.
- ceiling: `${}` interpolation inside JS template literals is treated as
  literal text — conservative-correct for round-trip fidelity (matches the
  minifier); code inside interpolation stays un-reindented. Upgrade path:
  recursive scanner on `${`..`}` if interpolated-code formatting is ever
  needed.
- Tests: `fallback_go_raw_string_round_trips` (braces/semis/newlines/
  closing-brace-in-literal), `fallback_js_template_literal_round_trips`,
  `fallback_backtick_literal_does_not_leak_protection` (code after the
  literal still re-indents). Existing suite (95 tests in shared::minify)
  unchanged and green.
- Found, out of scope (pre-existing, cosmetic): the `:` arm pads Go's `:=`
  (`s := x` → `s : = x` on fallback write-back). Disclosed in lessons.md;
  candidate for a follow-up WO if Go fallback write-back matters.
