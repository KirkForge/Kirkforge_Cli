# WO 48 — Python docstring heuristic drops triple-quoted ARGUMENTS inside parens — f("""...""") loses the argument on write-back

## Status: Planned

## Problem

P1. lang.rs:682-716 — the docstring heuristic treats a line-leading triple-quote inside parens as a docstring and strips it: result = f(\n    """\n    SELECT...\n    """\n) → result = f( — the argument is deleted from disk. List-of-strings loses every element. Fix: docstring stripping only applies at module/class/def statement start (check the preceding non-blank line ends with : or is module start), never inside brackets — track bracket depth and suppress docstring detection at depth>0.
