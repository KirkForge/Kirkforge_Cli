# WO 48.45 — python docstring heuristic strips triple-quoted ARGUMENTS inside parens

## Status: Done

## Problem

P1. src/shared/minify/lang.rs:682-716 — `minify_python`'s docstring
heuristic classifies ANY triple-quoted literal whose current output line is
blank as a docstring and drops it. A triple-quoted call argument
(`f(\n    """\n    SELECT ...\n    """\n)`) starts on a blank line → the
argument is deleted; the default-on read→envelope→write-back chain then
writes the file back without it. Same for list elements inside `[]`. Tests:
triple-quoted call argument round-trips; list-of-strings round-trips; real
docstrings still stripped; nested-parens string.

Source: Sweep 4 follow-on minify wave (kf-code-review.md, 2026-08-29,
HEAD 357ac36e / fae3ada2).

## Root cause

Docstring detection was purely positional-within-line ("current line is
blank") with no bracket-depth awareness and no notion of statement start —
every multi-line string literal that begins a line inside `()`/`[]`/`{}`
looks like a docstring to it.

## Approach

Track bracket depth in the python scanner and require, for docstring
detection, ALL of: depth 0; the quote is the first token on its line; the
preceding non-blank line of the output ends with `:` (block opener) or does
not exist (module start). Minimal correct fix — the drop mechanics are
unchanged, only the detection condition.

## Done

`minify_python` gained a `paren_depth` counter (`(`/`[`/`{` up, `)`/`]`/`}`
down, saturating — brackets only reach it outside strings/comments since
those arms `continue` first). Docstring detection is now
`paren_depth == 0 && current_line_blank && python_at_block_start(&out)`
where `python_at_block_start` = last non-blank line of `out` ends with `:`
or `out` has no non-blank line yet (module start). Also kills the
`lambda: """..."""` / `x = """..."""`-after-a-block-header false-positive
class (current-line check) that a colon-only rule would have introduced.
New tests: `test_minify_python_triple_quoted_call_argument_round_trips`
(minify + envelope→expand), `..._list_of_triple_quoted_strings_round_trips`,
`..._real_docstrings_still_stripped` (module/class/def),
`..._nested_parens_triple_quoted_string_survives` (`#` in body verbatim).
