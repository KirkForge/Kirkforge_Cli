# Workorder 8.1 — Multi-Model Benchmark Leaderboard

## Status: Planned

## Problem
The bench harness runs tasks against a single model (`qwen2.5:0.5b` in CI). There is no way to compare multiple models' performance on the same task set. ADR-038 mentions "multi-model comparison" as a goal but it was never built. The `BenchReport` has a `model` field but no `bench compare --models` subcommand or multi-model runner.

## Root cause
The bench harness was built for single-model runs. Multi-model comparison was always a goal but was deferred.

## Files to touch
- `src/cli.rs` — add `bench run-models --tasks <dir> --models <a,b,c> --summary <md>` subcommand
- `src/main/mod.rs` — add `handle_bench_run_models` that loops over models, runs all tasks for each, and produces a comparison table
- `crates/kirkforge-bench/src/lib.rs` — add `write_model_comparison(reports: Vec<BenchReport>) -> String` that produces a markdown table: Model | Tasks Passed | Avg Tokens | Avg Cost | Avg Duration
- `benches/baselines/` — store per-model baselines
- `docs/adr/038-task-benchmark-harness.md` — update with multi-model support

## Approach
1. `bench run-models` takes a comma-separated list of model names
2. For each model, run all tasks sequentially (same as `bench` but looped)
3. Collect all `BenchReport`s and produce a comparison table
4. Post the comparison as a PR comment (extend the existing bench CI job)
