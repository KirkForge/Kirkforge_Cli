# Workorder 8.3 — Bench Task Realism: Real-Repo Tasks with Tool Access

## Status: Planned

## Problem
WO 6.1 fixed the empty-toolset issue but 5 of the 20 bench tasks target the "real repo" (no setup files). These tasks depend on the repo's current state and break when the repo changes. WO 7.8 added 10 self-contained tasks, but the original 5 real-repo tasks remain fragile. Additionally, all tasks use a sandboxed toolset that may not include plugin tools (stratum, budget, draw) — so no bench task tests plugin tool usage.

## Root cause
The real-repo tasks were the original 5 from the MVP and were never converted to self-contained format.

## Files to touch
- `benches/tasks/add_adr.toml` — convert to self-contained setup with a fake `docs/adr/` dir
- `benches/tasks/add_cli_flag.toml` — convert to self-contained setup with a fake CLI
- `benches/tasks/add_test_for_function.toml` — convert to self-contained setup
- `benches/tasks/fix_clippy_warning.toml` — convert to self-contained setup
- `benches/tasks/refactor_extract_function.toml` — convert to self-contained setup
- `benches/tasks/` — add 5 new tasks that test plugin tool usage:
  - `use_stratum_compress.toml` — compress a large tool output using stratum
  - `use_budget_check.toml` — check budget status after generating output
  - `use_draw_render.toml` — render a .td.json diagram
  - `use_workflow_run.toml` — run a workflow template
  - `use_lsp_query.toml` — query LSP for symbol definitions

## Approach
1. For each real-repo task, create a self-contained setup with synthetic files that exercise the same skill (e.g., `add_adr` creates a fake repo with `docs/adr/README.md` to update)
2. For plugin tool tasks, the bench harness needs to register plugin tools in the sandboxed toolset. Check if `build_bench_toolset` already includes plugins or if it needs extending.

## Gate
```
cargo fmt --check && cargo test --locked --workspace --no-fail-fast --all-features
kirkforge bench verify-only --tasks benches/tasks/
```

## Done condition
- All 25 tasks (20 existing + 5 new) are self-contained
- No task depends on the real repo state
- 5 new tasks test plugin tool usage
- `bench verify-only` passes for all 25
- Depends on: WO 7.8 (bench task expansion)
