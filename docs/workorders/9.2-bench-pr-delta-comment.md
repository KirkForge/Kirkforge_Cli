# Workorder 9.2 — Bench PR Delta Comment

## Status: Planned

## Problem
The bench harness can compare two runs (`bench compare` CLI exists, WO 6.2)
and the CI runs bench on push to `main` (`bench-baseline.yml`). But there is no
PR-time delta comment: when a PR changes code in `src/session/`,
`src/adapters/`, `src/tools/`, or `crates/kirkforge-bench/`, CI does not run
bench against the PR branch and post a "tokens/cost/time vs main" comment.
The multi-model leaderboard (WO 8.1) and delta comparison (WO 6.2) exist as
code but are not wired into the PR review flow.

## Root cause
The `bench-baseline.yml` workflow runs on `push: [main]` and `schedule` only —
no `pull_request` trigger. The `ci.yml` bench job runs on PR but only runs
`verify-only`, not the full model-invoking bench. No step posts a comparison
comment to the PR.

## Files to touch
- `.github/workflows/bench-baseline.yml` — add `pull_request` trigger for
  bench-relevant paths; download the main-branch baseline artifact; run bench
  against the PR HEAD; compute delta vs baseline; post a PR comment with the
  comparison table (reuse `write_markdown_delta` from `kirkforge-bench`)
- `.github/workflows/ci.yml` — the existing `bench` job could be extended,
  but it's cleaner to keep the PR-delta in `bench-baseline.yml` (it already has
  the baseline artifact logic)
- `crates/kirkforge-bench/src/lib.rs` — if `write_markdown_delta` doesn't
  accept the right shape for a PR comment, add a `format_pr_delta_comment()`
  helper

## Approach
1. Add `pull_request` to `bench-baseline.yml` triggers with the same path
   filter as the `push` trigger
2. On PR: checkout PR HEAD, download the latest `main` baseline artifact
   (from the previous scheduled run or main push)
3. Run `bench run` against the PR HEAD with the same model (`qwen2.5:0.5b`)
4. Run `bench compare` against the baseline
5. Post the delta as a PR comment using `gh pr comment` or the
   `actions/github-script` action
6. Mark the comment job `if: always()` so it posts even if some tasks fail

## Gate
```
# Workflow YAML is not unit-tested; verify by:
# 1. Push to a PR branch touching src/session/ → bench job runs → comment posted
# 2. YAML lint: yq eval '.' .github/workflows/bench-baseline.yml
cargo fmt --check && cargo test --locked --workspace --no-fail-fast --all-features
```

## Done condition
- A PR touching `src/session/` triggers the bench job
- A PR comment is posted with the delta table (tokens/cost/time vs main)
- The comment includes pass rate, not just per-task deltas
- Depends on: WO 6.2 (delta comparison exists), WO 8.1 (multi-model exists, optional)
